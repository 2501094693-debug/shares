# 巴菲特规则引擎 · 规则对照文档

> 本文档描述系统中「巴菲特规则引擎」的**实际实现**,逐条给出:规则 → 公式 → 阈值 → 出处(代码位置 / 巴菲特原意)。
> 引擎为**纯 Python 实现,不调用大模型**,可复现、不幻觉。

## 0. 思想来源

核心思想来自**巴菲特 1986 年致股东信**的「所有者盈余」(Owner Earnings)公式:

```text
所有者盈余 = 净利润 + 折旧摊销 + 其他非现金费用 − 维持性资本开支
```

系统中因为**无法观测"维持性资本开支"**,把该公式做成**区间**:

- **上沿**:假设维持性投入 ≈ 折旧摊销,约等于报告盈利 → 宽松
- **下沿**:把当年资本开支全部当作维持性投入 → 保守

其余规则(有形回报、资本饥饿、四种生意、留存 1 美元测试、会计诚实)来自巴菲特历年股东信与演讲的公开表述。

## 2. 数据来源

- **强制刷新东方财富 F10**:利润表、资产负债表、现金流量表、主要指标、业绩报表
- 覆盖范围:`limit=60` 期定期报告,合并成 `merged` 序列
- 取数口径:默认取**最新一期定期报告**,再抽**同一报告类型**的历史期(三季报对三季报、年报对年报),以防口径错配

## 3. 单期计算口径(公式表)

取自 `_period_metrics`、表格生成函数:

| 指标 | 计算公式 | 说明 |
|---|---|---|
| (a) 归母净利润 | `PARENTNETPROFIT` | 所有者盈余的主体 |
| 扣非净利润 | `KCFJCXSYJLR` | 仅作对照,不替代 (a) |
| (b) 折旧摊销 | `FA_IR_DEPR`(或油气/投资性房地产折旧) + `IA_AMORTIZE` + `LPE_AMORTIZE` | 全部缺列时标「未披露」 |
| 资本开支 | `abs(CONSTRUCT_LONG_ASSET)` | 购建固定资产等现金流出绝对值,作 (c) 的保守锚 |
| 所有者盈余上沿 | (a) + (b) − (b) ≈ 报告盈利 | 假设维持性投入≈折旧 |
| 所有者盈余下沿 | (a) + (b) − 资本开支 | 折旧未披露时标「未披露」 |
| OCF−资本开支 | `NETCASH_OPERATE − 资本开支` | 自由现金流旁路核对,非 1986 公式 |
| 有形净资产 | 净资产 − 商誉 − 无形资产 | 剥离会计商誉 |
| 有形 ROE | 归母净利润 ÷ 有形净资产 | 剔商誉后的真实回报 |
| ROE | `ROEJQ` / `WEIGHTAVG_ROE`;缺失时用 净利润÷净资产 | 报告口径 |
| PPE/营收 | (固定资产 + 在建工程) ÷ 营业收入 | 资产轻重 |
| capex/D&A | 资本开支 ÷ 折旧摊销 | 资本饥饿度 |
| OCF/净利润 | 经营现金流 ÷ 归母净利润 | 利润含金量 |
| 毛利率 | `XSMLL`;缺失时 (营收−营业成本)÷营收 | 定价权 |
| 扣非占比 | 扣非净利润 ÷ 归母净利润 | 盈利质量 |
| 拟派现金股利 | `ASSIGN_CASH_DIVIDEND`;为空则从 `ASSIGNDSCRPT`(如 `10派280.2423元`)× 总股本估算;「不分配」记 0 | 分红能力 |

### 跨期指标

| 指标 | 公式 | 说明 |
|---|---|---|
| 增量资本回报 | Δ净利润 ÷ Δ(PPE + 营运资本) × 100% | 新增 1 元资本创造多少利润 |
| 负增量资本仍增利 | Δ资本 ≤ 0 且 Δ净利润 > 0 | 不追加资本也能增利,偏「伟大」 |
| 留存 1 美元(近似) | 累计净利润 − 累计股利 = 近似留存;对照 Δ净资产 | 巴菲特 one-dollar test 的可计算近似 |
| 发股稀释 | 最新股本 > 最早股本 × 1.05 | 1 美元测试需扣掉发股 |

## 4. 生意分类规则(阈值)

阈值常量(文件顶部):

| 常量 | 值 | 含义 |
|---|---|---|
| `HIGH_ROE` | 15.0% | 高回报门槛 |
| `MID_ROE` | 8.0% | 中等回报门槛 |
| `LOW_CAPEX_DA` | 1.3 | 低资本饥饿门槛 |
| `HIGH_CAPEX_DA` | 1.8 | 高资本饥饿门槛 |
| `PERIOD_LIMIT` | 8 | 同口径历史期上限 |
| `RECENT_LIMIT` | 12 | 混合序列上限 |

分类结果(模型**禁止改写**):**伟大 / 优秀 / 平庸 / 糟糕 / 数据不足**。判定逻辑(`_classify_business`):

| 结果 | 判据 |
|---|---|
| **数据不足** | 有形 ROE 与报告 ROE 均无法算出 |
| **伟大** | ROE ≥ 15% **且**(负增量资本仍增利 / capex/D&A ≤ 1.3 / PPE/营收 ≤ 25% 代理) |
| **优秀** | ROE ≥ 15% 且 capex/D&A > 1.3,且增量回报 ≥ 15% 或负增量资本仍增利;或高 ROE 但折旧未披露 |
| **平庸** | 中等回报(8% ≤ ROE < 15%);或高回报但增量资本回报一般 |
| **糟糕** | ROE < 8% 且仍在扩张(capex > 0 且扩张特征明显) |

## 5. 风险警示规则(`_risk_flags`)

命中即追加一条警示:

| 警示 | 触发条件 |
|---|---|
| 折旧摊销未披露 | 现金流附注全部缺列,下沿失效 |
| 现金流含金量低 | OCF/净利润 < 80% |
| 经营现金流为负 | OCF < 0 |
| 商誉过高 | 商誉 ÷ 总资产 > 15% |
| 非经常项目过多 | 扣非占比 < 70% |
| 发股稀释 | 最新股本 > 最早股本 × 1.05 |
| 外部注资/发股 | 期间吸收投资现金 > 0 |
| 受限盈利 | PPE/营收 > 40% 且 毛利率 < 25% |
| 类型糟糕 | 生意类型被判定为「糟糕」 |

## 6. 输出结构

引擎输出 `metrics`(全部指标)、`flags`(风险警示)、`tables`(5~6 张 markdown 表)、`text`(摘要)、`business_type`。

表格:
- `owner_earnings`:所有者盈余表(报告期 / (a) / 扣非 / (b) / 资本开支 / 上沿 / 下沿 / OCF / FCF)
- `capital`:资本与回报表(ROE / 有形ROE / 有形净资产 / PPE / PPE营收 / capex_D&A / OCF净利润 / 毛利率)
- `allocation`:资本配置表(拟派股利 / 分配股利 / 吸收投资 / 股本 / 借款 / 债券 / 还债 / 筹资CF / 商誉 / 扣非占比)
- `diagnosis`:综合诊断表(类型 / 上沿 / 下沿 / FCF / 增量资本回报 / 留存对照)
- `recent_all`:近期快照表
- `annual_owner`(仅当最新为季报/中报时):年报口径所有者盈余表

## 7. 已知局限(与巴菲特原意的差距)

1. **维持性资本开支不可观测**:只给上下沿区间,不给单点值,与巴菲特"精确到能取出的现金"存在差距。
2. **折旧依赖东财附注**:附注缺列时下沿直接失效。
3. **累计数口径**:中报/三季报的利润/现金流为累计数,不能与年报直接横比。
4. **不做估值**:引擎只读表,不给内在价值、安全边际。
5. **分类阈值是经验值**(15% / 8% / 1.3 / 1.8),非巴菲特原话,需按行业校准。
6. **负增量资本的"伟大"判定**可能被一次性因素(资产处置、会计调整)误导,缺少平滑。

## 8. 与巴菲特公开表述的对照

| 引擎规则 | 巴菲特出处 / 原意 |
|---|---|
| 所有者盈余上下沿 | 1986 年致股东信 Owner Earnings |
| 有形 ROE / 有形净资产 | 强调「经济商誉」而非会计商誉 |
| capex/D&A 资本饥饿 | 区分「喜诗糖果」与「资本黑洞」型生意 |
| 四种生意分类 | 高回报低投入 / 高回报高投入 / 低回报等类型 |
| 留存 1 美元测试 | 股东信 one-dollar test |
| 会计诚实(扣非、商誉) | 反复强调"会计是商业的语言"、警惕盈余管理 |
| 能力圈 / 看不懂不发乐观结论 | 规则引擎保守赋值 |
