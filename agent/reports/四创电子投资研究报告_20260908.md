## 4. 各维度分析摘要

### 4.1 商业模式（段永平视角）——2.0/5

1. **本质是“订单驱动型系统集成商”**，以雷达技术为核心，面向政府和行业客户提供电子信息系统与安全解决方案；项目制交付，无订阅制/经常性收入。
2. **缺乏平台/产品飞轮效应**：项目之间知识、数据难以复用，收入与用户数量之间没有累积性正反馈。
3. **护城河主要来自中电科体系身份与雷达技术积累**，但未转化为定价权；品牌是“准入门票”而非经济护城河。
4. **技术有壁垒，商业兑现不足**：低空安全仍处市场培育早期，公司自述“尚未形成规模化订单”。
5. **财务特征印证模式脆弱**：营收下滑28.5%时亏损扩大3倍，说明固定成本刚性极强，当前处于规模不经济区间。

### 4.2 财务（巴菲特视角）——1.0/5（数据可用性）

1. **本次数据采集严重失败**：结构化数据仅有公司名称与代码，无任何财务报表字段；联网搜索返回“四”字百科条目，与公司无关。
2. 所有核心财务分析——营收趋势、ROE、现金流、资产负债表、PE/PS/PB——**均无法执行**。
3. 从其他三位分析师交叉引用的数据可确认：2026H1营收4.84亿元、归母-1.34亿元、短期债务14.74亿元、货币资金2.48亿元。
4. 财务维度无法给出任何估值结论或安全边际判断，**需要重新拉取经审计年报、季报及行情数据**。
5. 该评分不代表四创电子真实财务状况好坏，仅反映本次数据管道的可用性缺陷。

### 4.3 行业格局与竞争（芒格视角）——2.5/5

1. **行业分化明显**：PCB/AI硬件景气高，2026Q1全球PCB产值同比+26.3%，嘉立创H1营收+54.13%、净利+73.54%；北斗卫星导航政策驱动扩容。
2. **四创未搭上高景气赛道**：同期公司营收-28.5%，与PCB龙头形成极端背离，说明公司大概率不是PCB行业实质受益者。
3. **低空安全赛道仍处亏损培育期**：四创、苏州科达均亏损；亿航智能Q1净亏1.26亿元、交付仅4架并裁员，下游需求未释放。
4. **竞争位势脆弱**：传统雷达/军工电子缺乏份额数据；PCB端面临嘉立创挤压；体系内国睿科技具备体制资源；低空安全无差异化优势。
5. **产业链位置不利**：处于中游集成环节，上游材料涨价、下游需求未起、现金流紧张，议价能力和回款能力弱。

### 4.4 风险与治理（李录视角）——2.0/5

1. **流动性风险为最高优先级**：货币资金2.48亿元 vs 短期债务14.74亿元，覆盖率仅约16.8%，公司持续失血但再融资/偿债安排不透明。
2. **管理层能力圈不清**：从雷达/安防扩展到PCB、低空安全、北斗等多概念，传统主业收缩、新业务多点开花但无一盈利。
3. **股权激励回购注销**（2026-07-21公告）是治理负面信号，暗示业绩考核不达标或核心人员离职，激励机制脱节。
4. **竞争与业务风险双高**：传统主业缺乏可持续护城河，新业务“有卡位但未见胜负手”；营收断崖式下滑、亏损扩大、概念与业务错位。
5. **长期确定性低**：公司能否熬到低空经济拐点，取决于集团战略定位、合肥试点成败和行业监管成熟度，均超出管理层直接控制范围。

## 5. 投资论点 Bull vs Bear

### Bull（多头论点）

1. **央企背景是隐性安全垫**：中国电科体系成员，极端流动性风险下存在集团支持/资产整合预期。
2. **低空经济战略卡位**：雷达技术延伸至低空安全具技术合理性，合肥UAM样板工程有地方产业生态加持。
3. **主题标签丰富**：低空安全、北斗、军工电子、国产替代等多个概念，若政策或订单落地，股价弹性可能较大。
4. **信息披露相对克制**：未发现虚假披露、立案调查或交易所处罚；公司主动澄清不参加特定产业大会，未迎合炒作。
5. **军工/安防具一定逆周期属性**：与宏观GDP波动相关性低，长期国家需求存在。
6. **存在困境反转期权**：若流动性安排明确、低空订单放量或营收恢复正增长，估值可能修复。
7. **股价可能已部分反映利空**：连续亏损与现金紧张已被市场讨论，若情绪出清，交易性反弹可能存在。

### Bear（空头论点）

1. **基本面快速恶化**：2026H1营收-28.5%，归母净利润-1.34亿元，亏损同比扩大约208%。
2. **流动性风险极高**：货币资金仅覆盖短期债务约17%，短债缺口14.74亿元，再融资依赖集团或银行续贷。
3. **新业务叙事未兑现**：公司自述低空安全“尚未形成规模化订单，仍处于市场培育早期”。
4. **热门标签与经营现实脱节**：PCB行业高增长，但四创营收下滑；市场标签并不等于业务实质。
5. **商业模式差**：项目制收入不可预测、季节性极端、盈亏平衡点未达到、缺乏定价权与经常性收入。
6. **竞争弱势**：PCB龙头嘉立创高增长碾压；体系内国睿科技资源更强；低空安全与苏州科达同步亏损。
7. **长期确定性低**：能否熬到低空拐点高度不确定，主营萎缩与投入同增形成“剪刀差”。

用段永平最朴素的标准先过滤一遍："这家公司赚钱吗？赚的是真金白银吗？十年后它还在吗？"

- **赚钱吗？** 2026年H1营收4.84亿元，同比**-28.50%**；归母净利润**-1.34亿元**，同比亏损扩大（去年同期-4343万元），亏损额约为去年同期的**3倍**。没有盈利，且亏损在加速。
- **赚的是真金白银吗？** 短期债务14.74亿元 vs 货币资金仅2.48亿元，**短期债务/货币资金≈5.9倍**。即使有利润也谈不上"真金白银"，现金流是紧绷的。
- **十年后还在吗？** 这个问题尚可回答"大概率还在"——央企中国电科体系背景，雷达与公共安全赛道，有存在价值。但"还在"不等于"是好生意"。

**核心判断：四创电子目前处于"有社会价值、有战略价值，但商业价值尚未兑现"的阶段。** 段永平会说："这是我要'跳过去'的公司——不是差公司，但商业模式上还不够'清晰易懂'，赚钱能力尚未被证明。"

## 二、商业模式本质：核心生意定义与收入结构

### 2.1 核心生意一句话定义

四创电子本质上是**以雷达技术为核心、面向政府和行业客户提供电子信息系统与安全解决方案的系统集成商**。其生意模式是 **"军方/政府订单驱动 + 项目制交付"** 的To G/To B模式，而非标准化产品/平台模式。

### 2.2 收入结构拆解（基于可获取的公开定位）

> ⚠️ **数据诚实声明**：本次已采集的结构化数据及联网搜索结果中，**未能获得四创电子2025年报及2026年中报的分业务板块收入明细**。以下业务板块分类基于公司公开的业务定位及新闻信息定性推断，**具体收入占比数据缺失，不进行杜撰填充**。

| 业务板块 | 业务性质 | 客户类型 | 收入模式特征 |
|---------|---------|---------|------------|
| 雷达及配套 | 气象雷达、航管雷达等 | 军方、民航、气象局 | 项目制、定制化、回款周期长 |
| 公共安全与应急 | 平安城市、应急指挥系统 | 地方政府 | 招投标、集成商模式、竞争激烈 |
| 电源与PCB制造 | 军工电源、PCB | 军工/工业客户 | 制造业逻辑，与雷达主业关联度有限 |
| 低空安全（新兴） | 低空监视、反无人机 | 尚处培育期 | 无规模化订单，技术验证阶段 |

### 2.3 商业模式定性结论

**这是一个"订单驱动型系统集成商"，而非"产品/平台型公司"。** 关键特征：

- **项目制为主**：收入呈明显季节性（2026年Q2营收占上半年64.8%），符合"年底集中交付验收"的政府/军方采购节奏。
- **无经常性收入**：缺乏订阅制、服务费、耗材等重复性收入，每一单都需要从零开始获客和交付。
- **盈亏平衡点高**：公司明确表示"营业收入规模尚未达到盈亏平衡点"（来源：南方财经网2026-07-14），说明固定成本和刚性费用对规模极为敏感，规模不足时亏损迅速放大。

**评分：★★☆☆☆（2/5）**——项目制集成商模式在段永平框架下属"辛苦的生意"：每单都辛苦、每单不累积、收入不可预期。

## 三、平台/产品飞轮效应：基本不成立

段永平投资网易、苹果、茅台的共同点是：**用户越多，产品越好，护城河越深**。飞轮的本质是"累积性正反馈"。

### 3.1 飞轮检验

| 飞轮要素 | 四创电子现状 | 判断 |
|---------|------------|------|
| 用户/客户增长是否带动产品价值提升？ | 项目制交付，A项目的经验/数据难以直接提升B项目价值 | ❌ 弱 |
| 是否有数据/网络效应累积？ | 雷达数据、安防数据受制于保密和产权边界，难以跨客户复用 | ❌ 弱 |
| 规模能否带来边际成本下降？ | 系统集成业务人力密集型，规模扩大边际成本下降有限 | ⚠️ 有限 |
| 品牌能否降低获客成本？ | 作为中电科体系一员，在军方/政府客户中有资质信任，但竞争对手同属央企体系 | ⚠️ 有限 |

### 3.2 唯一可能的"准飞轮"

在**雷达技术平台**层面，存在弱飞轮：长期项目积累的工程经验→技术迭代→在同类项目中竞标能力增强。但这更多是**线性能力积累**，而非乘法效应。技术积累依赖的是"时间+投入"，而非"用户数量"，飞轮不成立。

**评分：★☆☆☆☆（1/5）**——缺乏平台化收入和网络效应，项目之间的知识和数据难以有效复用形成飞轮。

## 四、护城河分析：逐项验证

### 4.1 品牌护城河

| 验证维度 | 实际情况 |
|---------|---------|
| To C品牌忠诚度 | 不适用（无C端产品） |
| To G/To B品牌信任 | 中电科系背景带来资质信任，"电子科技集团成员单位"是重要隐性背书 |
| 品牌是否带来定价权 | 未见，招投标模式下价格竞争激烈 |

**结论**：品牌是"准入门票"而非"护城河"。在军方/政府客户中，"资质+背景"是必要条件，但同类竞争者也具备（国睿科技、海康、大华等），不构成差异化定价能力。

**评分：★★☆☆☆（2/5）**

### 4.2 转换成本

这是四创电子潜在最强的护城河维度之一，但**缺乏量化数据支撑**。

| 转换成本来源 | 实际强度 |
|------------|---------|
| 系统嵌入（安防/指挥系统一旦部署，更换供应商成本高） | 存在，对存量客户有一定粘性 |
| 保密资质/信任关系 | 军品领域切换供应商需重新认证，转换成本高 |
| 技术标准锁定 | 未见证据表明四创能主导行业标准 |

**结论**：转换成本在军品和已部署系统中确实存在，但它并不能阻止新项目的竞争流失（每个项目单独招标）。转换成本保护的是**存量**，不保护**增量**。

**评分：★★★☆☆（3/5）**——从逻辑推导上存在，但需注意"保护存量≠创造增量"。

### 4.3 网络效应

**不适用。** 四创电子的客户之间不存在互联互通带来的价值增值。一个城市部署了四创的安防系统，不会增加另一个城市使用四创产品的价值。雷达产品同理。

**评分：★☆☆☆☆（1/5）**

### 4.4 规模效应

| 验证维度 | 实际情况 |
|---------|---------|
| 制造环节规模效应 | PCB/电源业务有一定规模效应，但该板块竞争激烈（参考嘉立创2026H1营收71.73亿元，是四创整体营收的14.8倍），四创不具备规模优势 |
| 系统集成规模效应 | 弱，人力密集型，规模扩大带来管理复杂度上升 |
| 采购议价能力 | 未见明显优势 |

**关键反证**：2026年H1营收下滑28.5%时，亏损急剧扩大（-1.34亿 vs 去年同期-0.43亿，亏损幅度远大于营收降幅），这说明**业务的固定成本刚性极强，当前非但没有规模效应，反而处于规模不经济的区间**。

**评分：★★☆☆☆（2/5）**

### 4.5 技术壁垒

这是市场给予四创电子关注度最高的护城河维度，但需要冷静拆解：

| 技术壁垒要素 | 实际情况 |
|------------|---------|
| 雷达技术积累 | 气象雷达、航管雷达有多年的工程积累，属于国内第一梯队（定性） |
| 技术壁垒转化为商业价值了吗？ | **尚未**。公司持续亏损，说明技术能力尚未转化为稳定的盈利模式 |
| 技术壁垒是可验证还是可推测？ | 军工技术细节缺乏公开可验证数据，无法精确评估 |
| 新兴低空安全 | 中国经营报明确报道："低空安全这类新兴业务受技术验证周期长、行业整体应用落地进度缓慢等因素影响，尚未形成规模化订单，仍处于市场培育早期阶段"（来源：中国经营报2026-08-22） |

**结论**：技术积累是真实存在的（天眼查/行业报道均可佐证雷达业务的历史积淀），但**"有技术"和"有商业护城河"是两回事**。段永平的核心问题是："这个技术壁垒带来定价权了吗？"——目前没有。

**评分：★★★☆☆（3/5）**——技术壁垒中最高的一项，但商业兑现不足。

### 4.6 护城河综合判断

**四创电子最大的"护城河"其实是其身份：中电科体系成员。** 这决定了它在特定的政府和军工市场拥有一张"入场券"，但这张入场券是**共享的**（国睿科技等同体系公司也有），且它并没有转化为持续的商业回报。

段永平式的结论：**这是一家有"牌照优势"的公司，但不是有"经济护城河"的公司。** 牌照让你能参赛，但不能保证你能赢。

**护城河综合评分：★★☆☆☆（2/5）**

## 六、业务矩阵与协同效应

### 6.1 业务矩阵

```
         传统成熟业务          新兴培育业务
高增长  ┌─────────────┬─────────────┐
        │   （无）     │  低空安全   │

低增长  ├─────────────┼─────────────┤
        │  雷达/安防   │  PCB/电源    │
        │（主体收入但同时下降）│ （低价竞争）   │
        └─────────────┴─────────────┘
```

### 6.2 协同效应真实性检验

市场叙事上常说"四创电子构建了从雷达技术到低空安全的延伸"，但协同效应的**财务证据缺失**：

- **技术协同（雷达→低空安全）**：逻辑上存在，雷达技术确实可用于低空目标探测。这是**理性延伸**，但延伸尚未产生规模收入。
- **客户协同（军方→政府安防）**：部分客户重叠，但采购决策链条完全不同，协同有限。
- **制造协同（PCB/电源与雷达整机）**：理论上是上下游延伸，但PCB业务面临市场化竞争（嘉立创等玩家体量远超四创），并未形成内部的成本优势。
- **财务实证**：2026年H1营收下滑28.5%，说明现有业务组合**没有实现对冲**——传统收入在萎缩，新业务尚未补位。

**结论**：业务矩阵是"概念上有关联性"，但"财务上尚未验证协同"。段永平会问："协同效应体现在哪里？报表上吗？"——目前没有。

**评分：★★☆☆☆（2/5）**

### 7.2 从段永平"不懂不做"视角的反面检验

段永平曾反复强调：**"我看不懂的，再好的公司也不投。"** 四创电子有几个让他"看不懂"的地方：

2. **新业务（低空安全）何时能贡献规模化收入？** 公司自身没有给出明确时间表。段永平非常反感"讲故事的预期"，他要的是"已经发生的好生意"。

3. **现金流的可持续性。** 短期债务14.74亿 vs 货币资金2.48亿。公司如何解决这个缺口？依赖母公司/大股东输血还是银行续贷？如果依赖外部输血，那么这家公司的"独立商业生存能力"就是存疑的。

### 7.3 段永平可能给出的总结

> **"这是一家国家需要的公司，但不是股东需要的公司。它承担的是国家战略功能，而不是创造超额资本回报。用'好生意'的标准看，它现在不配得上这个标签。"**

### 8.2 最终综合评分

**综合评分: 2/5**

**解读**：以段永平的"好生意"标准衡量，四创电子目前**不是好生意**。它更像一家"战略资产/国家功能平台"，而非"商业价值创造机器"。它的存在意义优先于它的盈利诉求。段永平不会投资这家公司，不是因为它是坏公司，而是因为它不符合"清晰、简单、可预测的持续盈利"这一最基础的门槛。

### 8.3 需要诚实标注的数据缺口

| 缺失数据 | 影响 |
|---------|------|
| 分业务板块收入/毛利率分解 | 无法精确判断雷达/安防/PCB各板块的盈利贡献和趋势 |
| 应收账款及账龄结构 | 无法判断To G业务真实现金回款质量 |
| 经营现金流净额 | 无法判断"亏损"与"现金流"的偏离程度 |
| 在手订单/新签合同额 | 无法判断未来1-2年收入的可预见性 |
| 大股东注资/担保情况 | 无法评估现金流困境的缓冲能力 |

### 8.4 非共识观点（本报告的核心增量）

1. **"低空经济"故事掩盖了基本面恶化的事实。** 市场把四创电子当作低空经济标的炒作，但公司自己披露低空安全业务"尚未形成规模化订单"。2026年H1的亏损来源于成熟业务的下滑+新兴业务的投入，**不是"黎明前的黑暗"，而是"主战线在溃缩"**。
