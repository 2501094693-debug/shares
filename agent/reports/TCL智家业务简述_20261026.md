# TCL智家 业务简述

### 一、这家公司做什么

TCL智家的生意，一句话说：造冰箱、冷柜、洗衣机，然后卖出去赚钱。公司旗下两个干活的主体：合肥家电做TCL自主品牌的冰箱和洗衣机，客户是普通家庭和渠道商；奥马冰箱专做冰箱ODM（白话就是给别的品牌贴牌代工），客户主要是海外品牌商和大零售渠道。收入来自一次性卖家电，不是订阅、不是抽成。〔来源：2025年年报 PDF · 管理层讨论；2026年半年报 PDF · 管理层讨论〕

对家庭用户，它卖的是「食材更保鲜、衣服洗得干净、省电、不串味、能嵌入橱柜」的实际用处；对海外贴牌客户，它卖的是「你不需要自建工厂，我能稳定、便宜、保质保量地供冰箱」，客户付钱买的是供应链能力。渠道方（经销商、电商平台、海外零售）则多了一个有品牌、有供货能力的产品线。〔来源：2025年年报 PDF · 管理层讨论；2025年年报 PDF · 核心竞争力分析〕

用户价值有具体产品支撑：TCL双磁鲜冰箱做到肉类7天紧实锁汁、冷冻100天鲜嫩不柴；超级筒洗衣机洗净比1.33，靠大筒径和智能算法解决领口袖口顽渍；奥马全嵌母婴冰箱能零距离嵌入橱柜，日均耗电0.89度，除菌率99.99%。这些都是围绕「好吃、干净、省电、好看」在做事，不是空泛概念。〔来源：2025年年报 PDF · 管理层讨论〕

### 二、商业模式本质与收入结构

核心生意类型：一次性耐用消费品销售。冰箱、洗衣机属于耐用品，置换周期长，用户不会年年买，所以公司增长主要靠新客户、海外市场和新品类，而不是靠同一批用户的反复购买。这与订阅制、平台抽成有本质区别。〔来源：2025年年报 PDF · 主营业务分析；2026年半年报 PDF · 管理层讨论〕

成本与利润来源：这是一门重资产、薄利生意。2025年营业成本中，原材料占84.20%，压缩机、板材等价格波动直接决定利润。利润主要来自规模摊薄和制造效率——全球产能超2000万台、奥马冰箱年出货量超1400万台，规模越大，单位制造成本和采购成本越低。所以它赚的是「省出来」的钱，不是品牌溢价的钱。〔来源：2025年年报 PDF · 营业成本构成；2025年年报 PDF · 核心竞争力分析〕

### 三、飞轮如何运转

TCL智家不是平台型生意，公开资料看不到用户之间的网络效应。但存在一个制造业增长循环：先靠研发做出爆品（如超级筒、双磁鲜、奥马母婴冰箱），再用TCL品牌和海外渠道把产品卖到更多家庭，卖得越多，规模越大，采购和制造成本越低，进而有更多钱继续投研发、建产能、进新市场。〔来源：2025年年报 PDF · 核心竞争力分析；2026年半年报 PDF · 管理层讨论〕

这个循环近一年有转动迹象：自有品牌海外收入2025年同比增长115%，2026年上半年再增77.07%；合肥家电海外收入连续两年超40%增长，2025年海外占比超过50%；奥马冰箱连续17年出口第一，规模效应进一步巩固定价空间。这不是互联网式的「用户越多成本越低」飞轮，而是「产品→规模→成本→再产品」的制造业循环。〔来源：2025年年报 PDF · 管理层讨论；2026年半年报 PDF · 管理层讨论；证券日报网 2026-07-10〕

### 四、护城河逐项验证

1. 品牌/定价权：部分成立。TCL是全球知名消费电子品牌，连续9年入围中国全球化品牌50强，品牌力有支撑；但TCL冰箱洗衣机在所在品类不是绝对龙头，奥马主要是ODM贴牌，面向B端客户，品牌溢价有限。洗衣机毛利率约13.68%，说明提价空间很小。结论：品牌有，但定价权不强。〔来源：2025年年报 PDF · 核心竞争力分析；2025年年报 PDF · 主营业务分析〕

2. 转换成本：不成立或很弱。家庭用户换冰箱洗衣机时换品牌几乎没有经济成本；ODM客户虽然依赖稳定供货和品质，但从客户角度看，价差和产能多处可替代，切换成本不高。年报披露的竞争风险也提示市场是多维竞争，没有锁定客户。结论：不成立。〔来源：2026年半年报 PDF · 风险披露；2025年年报 PDF · 主营业务分析〕

3. 网络效应：不成立。家电制造没有用户规模越大、产品价值越高的特性，终端用户之间不产生网络价值。公开资料未披露此类机制。〔来源：2025年年报 PDF · 管理层讨论；2026年半年报 PDF · 管理层讨论〕

4. 规模效应：成立。奥马冰箱年出货量超1400万台，公司全球产能超2000万台，连续17年中国冰箱出口第一、连续18年出口欧洲第一。这种规模带来集中采购、共享产线、单位成本下降，是公司最扎实的护城河。〔来源：2025年年报 PDF · 核心竞争力分析；2025年年报 PDF · 管理层讨论〕

5. 技术/工艺/资质壁垒：部分成立。截至2025年末，授权专利2725项，研发人员1296名，多项技术获「国际领先」认证，产品通过CNAS、SGS、CSA、TUV等全球认证。但冰箱洗衣机的技术演进相对成熟，这些壁垒难以形成强排他性，对手可追赶，尤其洗衣机毛利薄，技术溢价有限。结论：部分成立。〔来源：2025年年报 PDF · 核心竞争力分析；2026年半年报 PDF · 核心竞争力分析〕

整体判断：护城河中等偏窄。最有价值的是规模和出口渠道，品牌与技术提供一定差异化，但不足以带来强定价权。近一年公司加码泰国基地和自有品牌出海，海外供应链护城河在变宽；但同时受汇率、关税、原材料挤压，盈利波动大，整体不能算宽。〔来源：2026年半年报 PDF · 管理层讨论；2026年半年报 PDF · 公司面临的风险和应对措施〕

### 五、业务矩阵与协同效应

业务矩阵简洁：合肥家电（TCL品牌冰箱+洗衣机）和奥马冰箱（ODM+少量OBM）两条线。二者共享采购、研发、制造体系和全球化渠道。间接控股股东TCL实业有全球销售平台和售后平台，公司可借力，减少自建渠道成本，这是可见的协同，不是空话。〔来源：2025年年报 PDF · 核心竞争力分析；证券日报网 2026-07-10〕

近一年没有分散主业的动作：泰国一期30万台冷柜投产、二期140万台冰箱建成试生产；国内冰箱单线日产突破4000台；新品AI超级筒、奥马520PLUS母婴冰箱、TCL双磁鲜冰箱全部落在冰箱洗衣机主赛道。这些是产能、产品、渠道的加固，不是乱跨界。〔来源：2026年半年报 PDF · 管理层讨论；证券时报网 2026-09-14；上海证券报 2026-09-14〕

### 七、段永平视角：这是不是一门好生意

这门生意我看得懂。就是造冰箱、冷柜、洗衣机，卖硬件赚钱。客户真实、需求稳定，不是那种需要我猜半天的模式。哈，比很多花里胡哨的生意清楚。〔来源：段永平视角·综合前述定期报告〕

差异化不够。TCL品牌整体有名，但冰箱洗衣机不是它的最强项，用户不会因为叫TCL就愿意多付很多钱。奥马更是给人家贴牌，赚的是效率和成本的钱。差异化不足，就只能拼成本和规模，很辛苦。〔来源：段永平视角〕

定价权弱。洗衣机毛利才13%左右，冰箱冷柜也就27%，这还是在海外冲规模的情况下。价格一涨，客户可能就找别的厂，这种生意没有「爱买不买」的底气。所以它只能靠省、靠快、靠出海，赚的是辛苦钱。〔来源：段永平视角〕

竞争优势能不能持续？规模效应是真的，连续出口第一也是真的，但这个护城河不宽，同行也能建厂、也能出海。要维持它，得不断投研发、建海外基地、升级产线，不烧钱不行，烧了也不一定能躺赢。十年后冰箱洗衣机的需求还在，公司大概率还在，但能不能一直领先，不好说。〔来源：段永平视角〕

本分方面我觉得还行。公司做的事基本围绕用户要的保鲜、洗净、省电、嵌入，没乱搞什么不相关的东西。问题是这个行业天然辛苦，本分能少犯错，但不能把辛苦生意变成好生意。〔来源：段永平视角〕

综合判断：这是一门「辛苦的生意」。看得懂，也有规模、有出口本事、比较本分，但差异化不够、定价权弱、利润受汇率和原材料挤压，护城河中等偏窄。不是坏生意，但也谈不上好生意。〔来源：段永平视角〕

一句话：造冰箱洗衣机，本分、有规模，但差异化不够、毛利薄，靠效率赚辛苦钱，十年后还在，但不是好生意。〔来源：段永平视角〕
