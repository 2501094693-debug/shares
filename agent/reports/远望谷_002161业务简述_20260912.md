# 远望谷 002161 业务简述

### 一、这家公司做什么（一句话本质 + 用户/客户价值）

远望谷本质上是给铁路、图书馆、服装零售等企业客户提供「RFID 身份识别 + 数据采集」的设备和整套系统，让物理世界的物品有了数字化身份证，客户靠它做自动识别、追踪、盘点和管理；公司面向行业客户直销，靠卖硬件、方案和配套集成赚钱，国内业务占营收七成。〔来源：2025年年度报告·管理层讨论与分析；2025年年度报告·主营业务分析〕

对铁路客户来说，价值是把火车车号识别、设备状态监测做成自动化、少人化，把运行维护从「按计划修」拉到「按状态修」，降低人工巡检和停运成本；这份价值建立在近30年车号识别数据积累和100万套以上的累计装车存量上。对图书馆客户，价值是一套从自助借还到机器人盘点、安防门禁的全场景无人化系统，让馆员少做重复劳动、读者少排队。对服饰零售客户，价值是每一件衣服从工厂、仓储到门店的全程数字追踪，解决库存不准、盘点慢、渠道串货这些实际问题。〔来源：2025年年度报告·管理层讨论与分析；2026年半年度报告·管理层讨论与分析〕

从财务数据看，2025年公司收入规模约6.03亿元，体量不算大；2026年上半年营收2.49亿元、同比下滑11.34%，扣非归母净利润为 -3884万元，主业本身处于微亏状态。说明这是一门「产品有真实客户价值、但规模偏小、盈利偏弱」的B端技术生意。〔来源：2025年年度报告·主要会计数据；2026年半年度报告·主要会计数据〕

### 二、商业模式本质与收入结构

远望谷最贴切的商业模式是「B端项目制 + 产品直销」。客户是企业或机构，不是消费者；交易模式是直销，没有中间渠道；收入里没有订阅费或平台抽成，而是一单一单地做项目、卖设备和交付解决方案。根据2025年报，销售模式为100%直销。〔来源：2025年年度报告·主营业务分析·营业收入构成〕

收入结构按产品分，2025年以「物联网解决方案」占绝对大头（83.24%，毛利率41.07%），「物联网应用产品」占11.02%（毛利率31.53%）；2026年上半年解决方案收入占比降至69.29%（毛利率40.55%），应用产品占比上升至24.01%（毛利率32.88%）。这说明应用产品销售增长较快，但毛利率比解决方案低约8个百分点。地区上，2025年国内收入占71%（毛利率45.82%）、国际占29%（毛利率33.10%），国内赚钱质量明显好于出海业务。〔来源：2025年年度报告·主营业务分析·收入与成本；2026年半年度报告·主营业务分析·收入与成本〕

从成本利润来源看，这是一门「偏重资产」的生意。公司有自己的标签封装生产线、多功能标签层合生产线、产业园，截至2026年6月末固定资产账面价值4.33亿元，占总资产17.14%。同时它又不是纯制造，集成交付、客户定制、运维服务很重，2026年6月末存货1.64亿元、应收账款2.15亿元，说明项目交付周期长、回款占款。利润端更依赖「解决方案+高毛利国内客户」的结构，应用硬件多卖一点、出海多一点，毛利率就往下掉。〔来源：2026年半年度报告·资产及负债状况分析；2025年年度报告·主营业务分析〕

### 三、飞轮如何运转

从年报披露看，远望谷不是平台型生意，没有用户规模自我催化的网络飞轮。它的增长循环是「技术/场景深耕 → 头部标杆项目 → 行业口碑 → 同行业复制扩品」：在铁路、图书馆、服饰零售三个行业里，先用核心产品和方案打进大客户，再用行业标准和先发份额形成稳定现金流，然后往烟草、电力、核电、文旅、宠物等相邻场景复用RFID技术。年报明确称「以技术复用打开增量空间」。〔来源：2025年年度报告·管理层讨论与分析；2026年半年度报告·管理层讨论与分析〕

这个循环有一定黏性，但动能不算强。证据是：数智文化板块2025年签约百万级以上项目数量同比增25%、合同总额增47%，说明在细分场景有口碑复制；但公司整体扣非净利润仍亏损，2026H1营收下滑，说明场景复制的速度赶不上成熟业务波动的拖累，飞轮转得比较费劲。公开资料看不到平台式的自我强化飞轮，增长主要靠「一个行业一个行业地做深、再靠技术积累横着铺新的垂直场景」。〔来源：2025年年度报告·管理层讨论与分析；2026年半年度报告·主要会计数据〕

### 四、护城河逐项验证

**1. 品牌 / 定价权：部分成立。** 公司是国内RFID行业首家上市公司、国家第八批制造业单项冠军企业，在铁路车号识别领域「牢牢占据近半数市场」，在图书馆市场「海内外用户超万家」。品牌在B端细分场景里有认知度，但财务上定价权体现不足：2025年物联网行业整体毛利率39.86%，2026年上半年降到38.72%，国内业务毛利率也仅42%-46%，说明客户愿意为它的方案付溢价、但溢价空间有限，涨价能力没有被强验证。〔来源：2025年年度报告·管理层讨论与分析·公司所处行业地位；2025年年报·主营业务分析；2026年半年度报告·主营业务分析〕

**2. 转换成本：成立。** 铁路车号自动识别系统已装入铁路系统生产运营流程，累计装车量突破100万套，替换成本高且一旦采用会形成长期运维关系；图书馆用户一旦接入其RFID系统和平台，切换供应商意味着重新布设备、换软件、做数据迁移。转换成本在三个基石行业里是真实存在的。〔来源：2025年年度报告·公司所处行业地位；2026年半年度报告·公司所处行业地位〕

**3. 网络效应：不成立。** 远望谷是B2B设备与方案商，客户之间不彼此创造价值；图书馆客户数量再多，也不会让铁路客户的产品更好用。年报中没有披露任何跨客户网络效应或数据飞轮的证据。〔来源：2025年年度报告·核心竞争力分析〕

**4. 规模效应：部分成立。** 公司拥有从芯片、标签、读写器到系统集成的全产业链能力，建有自有封装产线和产业园，规模上来能摊薄制造成本；年报称数智文旅业务「规模效应带来成本摊薄」。但公司2025年营收仅6.03亿元、2026H1营收2.49亿元，绝对规模不大，管理、研发、销售费用高企，规模效应不足以让公司稳定盈利。〔来源：2025年年度报告·管理层讨论与分析；2025年年度报告·主营业务分析；2026年半年度报告·主要财务数据〕

**5. 技术 / 工艺 / 资质壁垒：成立。** 公司累计获得授权专利和专有技术超600项（其中发明专利85项，2026年中报为86项），参与制定国家标准7项、行业标准17项，拥有电子标签芯片设计、读写器制造等全链条能力，且是国家级制造业单项冠军。技术壁垒在RFID行业是真实成立的，尤其铁路特种标签、超高频芯片等环节。不过另一面是这项护城河一直在被持续研发投入维持——公司研发投入占营收比例连续多年超10%，说明要守住技术位，花钱不能停。〔来源：2025年年度报告·核心竞争力分析；2026年半年度报告·核心竞争力分析〕

**概括**：远望谷的护城河不是宽到可以高枕无忧，而是「在少数B端细分场景里真实、但整体偏窄」。转换成本和技术壁垒是它最扎实的部分，规模效应和品牌溢价都不够强，网络效应没有。近一年看，公司在数智文旅、宠物经济、核电等横向铺开，护城河宽度没有明显变厚，反倒是「主业内生增强、外延并购光通信」的动作，让业务更多元、经营更复杂。护城河的看点还是铁路和图书这两个老场景，别的都还早。〔来源：2025年年度报告·管理层讨论与分析；2026年半年度报告·管理层讨论与分析〕

### 五、业务矩阵与协同效应

公司业务矩阵可以用「3+1+X」概括：三个基石场景（数智铁路、数智文化、数智零售）是基本盘，一个AI赋能贯穿所有业务（视觉盘点、大模型、数据平台），加上消费物联网（宠物智能硬件）和数智文旅两个新增长方向，再往外是烟草、电力、核电等孵化业务。协同真实发生在「技术复用」层面，即同一套RFID感知硬件、芯片、读写器和数据平台，在不同行业换场景卖；而不是客户交叉、渠道共享或平台数据协同。〔来源：2025年年度报告·管理层讨论与分析；2026年半年度报告·管理层讨论与分析〕

近一年公告中的动作，大体上是「修好主业、往外拓边」的组合。收购维度，2026年9月公告拟收购深圳光泰通信100%股权、切入光通信设备赛道，这是跨出RFID主业的动作，公开资料显示收购资金来源为自有资金及自筹资金；2026年3月公司以3800万元控股合肥荣科恒阳电源科技（持股30.6155%、第一大股东），也是往新能源电源方向的外延。这两笔并购跟RFID主业的直接协同性，年报未作详细论证，不能简单说「改善主业」。〔来源：中国证券网·2026-09-11 报道；2026年半年度报告·管理层讨论与分析·内生+外延〕

内生维度更能看清协同逻辑：2026年上半年公司中标国内头部互联网电商平台线下门店RFID项目、拿下中海油和中广核的RFID采购框架，说明基石技术与成熟场景在往零售、能源复用；宠物智能喂食器用的是「自研双频RFID识别模组」，属于把B端技术往C端消费硬件迁移的尝试，这个协同是真实的，但目前体量还小。总体看，主业协同成立，外延并购是否「填坑」还是「挖坑」，得看后面经营结果，眼下资料不足以证明协同。〔来源：2026年半年度报告·管理层讨论与分析；2026年半年度报告·主营业务分析〕

### 七、段永平视角：这是不是一门好生意

这门生意我看得懂，就是卖物联网识别设备和方案给铁路、图书馆、服装厂这些客户，帮人家把东西管清楚。技术好不好另说，生意本身不复杂，不是那种看不懂的生意。但看得懂不等于看得上。它的收入规模才6个亿，扣非利润还是负的，说明这是一门要持续投钱、卖一单赚一单的辛苦活。哈，毛估估一下，这不是那种会自己变大的生意。〔来源：2025年年度报告·管理层讨论与分析〕

差异化呢，它有，在铁路和图书馆这两个老场景里做得深，客户换不掉它，这是真本事。但要打价格战的地方也不少，尤其是出海和应用硬件，毛利率才三成出头，说明很多单子是拼出来的，不是客户非你不可。定价权方面，它没有真正意义上的定价权，涨价客户会不会跑，从毛利率往下走这点看，它也得看客户脸色。护城河有，但是窄的，十年后铁路和图书这两个老客户大概率还在，可别的赛道能不能成气候，现在看不清楚。更让我皱眉的是——老要烧钱，并购光通信、控电源公司，这些跟主业有什么关系？看不懂就宁可等。它算不算围着用户转？算，但守住本分有点打折扣，因为外延动作我看着有点散。综合起来，这是一门一般生意，不是我看得上的好生意，但还不至于完全看不懂。〔来源：2026年半年度报告·资产及负债状况分析；2026年半年度报告·管理层讨论与分析；中国证券网·2026-09-11〕

**一句话**：技术有积累、老客户有黏性，可惜赚的是辛苦钱，规模小还老要烧钱，生意成色一半一半。〔来源：2025年年度报告·主营业务分析；2026年半年度报告·主要会计数据〕
