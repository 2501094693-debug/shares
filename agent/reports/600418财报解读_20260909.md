## 一、近一年财报速览

### 原始数据

〔来源：东方财富 F10 利润表、现金流量表；巨潮资讯 2025年报、2026一季报、2026半年报公告〕

交叉验证：2026中报营业总收入、归母净利润、营业利润在东财主要指标 / 利润表 / 业绩报表中分别为 221.8亿、-7.49亿、-7.03亿，校验通过。〔来源：东财主要指标 / 利润表 / 业绩报表〕

### 解读
最近一年最重要的三个变化如下：

**1. 营收增长加速，但利润仍深度亏损——低于“扭亏”预期。**  
2026中报营业总收入 221.8亿，对照 2025中报 193.97亿，同比增长约 14.35%；2025年报营业总收入 465.69亿，同比也增长 10.35%。但 2026中报归母净利润为 -7.49亿，仅比 2025中报 -7.73亿收窄约 3.1%；2025全年归母净利润 -17.03亿，仍接近 2024年 -17.84亿的水平。也就是说，营收增长没有转化为利润，主业仍在赔钱。

**2. 经营现金流大幅转差——低于预期。**  
2025年报经营现金流为 33.95亿，但这是全年累计数。进入 2026年，经营现金流急剧恶化：2026一季报 -39.02亿，2026中报 -52.88亿。2026中报经营现金流流出额是 2025中报 -31.47亿的约 1.68倍。利润已经为负，经营现金流还大幅流出，说明这一年不但没赚钱，账面现金也在被消耗。

**3. 报告期利润数据通过交叉验证，但累计亏损仍在扩大——符合“持续亏损”判断。**  
2025年报归母净利润 -17.03亿，2026中报 -7.49亿；2025三季报 -14.34亿，2026一季报 -6.06亿。亏损不是偶发单季波动，而是跨报告期连续存在。整体看，近一年财报明显低于“有望扭亏”的预期，属于**低于预期**。

〔来源：东方财富 F10 主要财务指标 / 业绩报表〕

### 解读
**收入增长没有持续加速。**  
营业收入从 2021年 403.11亿、2022年 365.77亿，到 2023年 450.16亿，再到 2024年 422.02亿、2025年 465.69亿，五年间走了“降—降—升—降—升”的节奏。2025年 465.69亿虽创五年新高，但同比 +10.35% 并不代表趋势性加速；2024年刚经历过 -6.25% 的回落。

**利润质量很差。**  
2021年归母净利润虽为 2亿，但扣非净利润为 -18.84亿；2023年归母净利润 1.52亿，但扣非净利润为 -17.18亿。这说明当年利润主要靠非经常性损益支撑，并非主业赚钱。2024年归母净利润 -17.84亿、扣非净利润 -27.41亿；2025年归母净利润 -17.03亿、扣非净利润 -25亿。扣非净利润连续五年为负，主业长期不盈利。营业利润方面，2025年 -16.85亿，比 2024年 -18.89亿略有收窄，但仍处于巨额亏损。利润质量没有实质改善，只是亏损幅度小幅波动。

〔来源：东方财富 F10 主要财务指标〕

### 解读
**毛利率在改善，但整体回报仍为负。**  
毛利率从 2021年 8.16% 提升到 2025年 12.28%，五年提高了约 4.12个百分点，说明产品结构或成本控制有所改善。但净利率 2025年仍为 -3.81%，经营利润率 -3.62%，意味着毛利改善被费用、减值或其他项目吞噬，最终没有变成利润。

**高回报完全不存在。**  
2025年报 ROE 为 -16.18%，ROA -3.54%，ROIC -8.86%。ROE 在 2023年短暂回到 1.13%，但 2024年跌至 -14.51%，2025年进一步下降到 -16.18%。这不是“高回报是否可持续”的问题，而是负回报还在扩大。该公司当前没有体现出可识别的定价权；12.28% 的毛利率在商用车制造中并不高。资产负债率从 2021年 65.78% 升至 2025年 79.07%，说明负回报还叠加了更高的财务杠杆，净资产被亏损持续侵蚀。

### 解读
**利润没有真正变成现金。**  
2025年报经营现金流 33.95亿，比 2024年 27.11亿增加，但归母净利润为 -17.03亿。经营现金流/净利润为 -199.38%，这个指标在净利润为负时已经失真，不应理解为“利润质量好”。更有意义的是收现比：2025年报销售商品收现 427.81亿，对应营业总收入 465.69亿，收现比约 91.9%；2026中报销售商品收现 186.61亿，对应营业总收入 221.8亿，收现比约 84.1%。收现比下降，说明收入越来越难足额变成现金。

**2026上半年现金流明显恶化。**  
2025年报经营现金流 33.95亿，但 2026一季报 -39.02亿、2026中报 -52.88亿。2026中报筹资现金流 32.16亿，投资现金流 -20.79亿，现金净增加 -39.31亿。也就是说，经营和投资都在消耗现金，缺口靠筹资来补。

**资本开支在增加。**  
2025年报购建固定资产 17.22亿，2026中报购建固定资产 14.02亿，已相当于 2025全年的约 81.4%。公司在营收亏损、经营现金流为负的情况下仍在加码固定资产投资，现金压力更大。

**必须点名：FCFF 口径存在明显差异。**  
东财 FCFF 与“经营现金流 − 购建固定资产”并不一致。例如 2025年报经营现金流 33.95亿 − 购建固定资产 17.22亿 = 16.73亿，但表列 FCFF 为 29.82亿；2023年报经营现金流 33.96亿 − 20.6亿 = 13.36亿，但表列 FCFF 为 -34.11亿。差异远超 1%。因此后文用 FCFF 做估值时，只能把它当作参考口径，不能当作可支配现金。

### 解读
**账面现金增加，但负债更重。**  
2025年报货币资金 171.4亿，高于 2024年 132.56亿，也高于 2023年 153.46亿。但总负债 402.31亿，资产负债率 79.07%，为五年最高。2021年资产负债率还是 65.78%，到 2025年已升至 79.07%。现金增加的同时，负债增长更快，净资产反而从 2021年 158.67亿减少到 106.48亿。

**流动性偏紧。**  
2025年报流动比率 0.8x，速动比率 0.72x，均低于 1。流动比率从 2021年 1.14x、2023年 1.08x，一路降至 0.8x；速动比率从 1.02x 降至 0.72x。这意味着流动资产已经不能覆盖流动负债，短期偿债压力较大。短期借款公开资料未披露，因此无法进一步判断有息短期负债的具体规模。

**存货与应收没有明显恶化，但资产质量一般。**  
存货从 2023年 47.46亿下降到 2025年 30.13亿，可能是去库存；应收 2025年 30.61亿，与 2024年 31.05亿基本持平，较 2021年 21.82亿明显上升。存货与应收账款没有大幅攀升，但资产负债表整体压力主要来自负债率上升和净资产缩水。

## 七、安全边际：内在价值 vs 当前股价

### 原始数据
| 估算项 | 数值 | 口径 |
|---|---:|---|
| 当前股价 | 20.31 | 东财盘口 |
| 总市值 | 457.82亿 | 股价×总股本 |
| PE_TTM | -27.27 | 盘口 |
| PB | 3.69 | 盘口 |
| PS_TTM | 0.94 | 盘口 |
| 盈利收益率 | — | 1/PE_TTM |
| FCF Yield | 6.51% | 最近年报FCF/市值 |
| 历史PE中位 | 134.52 | 东财日频估值序列 |
| 内在价值A | -44.66 | EPS×历史PE中位 |
| 安全边际A | 145.48% | (IV-股价)/IV |
| 内在价值B | 13.23 | 每股FCF×10 |
| 内在价值C | 19.84 | 每股FCF×15 |
| 安全边际B | -53.52% | 对应FCF×10 |

〔来源：用户预计算、东方财富盘口、历史估值序列〕

### 解读
**“EPS×历史PE中位”的内在价值A不适用。**  
当前每股收益 -0.332 元，历史PE中位 134.52，乘出内在价值A为 -44.66 元，为负值。负的内在价值没有经济意义，安全边际A 145.48% 也只是数学结果，不能作为投资依据。市盈率法在公司亏损时失效。

**FCF 倍数法给出的区间为 13.23—19.84元。**  
内在价值B 13.23元，是按 2025年报自由现金流 29.82亿、总股本 22.54亿，得到每股FCF约 1.323元，再乘以 10倍得出；内在价值C 19.84元，是每股FCF乘以 15倍得出。当前股价 20.31元，已经高于 FCF×15 的上限 19.84元，更高于 FCF×10 的 13.23元。对应 FCF×10 的安全边际B为 -53.52%，意味着当前股价比该口径内在价值高出约 53.52%。

**但 2025年报 FCF 的可持续性存疑。**  
2026中报经营现金流已经为 -52.88亿，若按“经营现金流 − 购建固定资产”粗算，2026上半年 FCF 约为 -66.90亿；再叠加前述 FCFF 口径差异，2025年报 29.82亿的自由现金流不能简单外推。若以 2026年上半年的现金创造能力看，内在价值应显著低于 13.23元。

**明确区间结论：**  
可接受的内在价值参考区间为 **13.2—19.8元**，中值约 **16.5元**。当前股价 20.31元高于区间上限，没有安全边际。若 2026年全年自由现金流转负或继续大幅流出，该区间还应下调。

## 八、巴菲特视角评估（结论）

**1. 生意可理解性：3 / 5**  
商用车/载货车制造，商业模式看得懂：造车、卖车、赚差价。但它重资产、强周期，盈利波动极大。

**2. 财务质量与护城河证据：1 / 5**  
2025年报 ROE -16.18%、ROA -3.54%、毛利率 12.28%、净利率 -3.81%；2025年报经营现金流 33.95亿，但 2026中报经营现金流 -52.88亿；扣非净利润 2021—2025年连续为负。这些数字不支持公司拥有宽护城河，甚至不支持主业持续盈利。

**3. 资产负债表与“活下去”能力：2 / 5**  
货币资金 171.4亿，但总负债 402.31亿，资产负债率 79.07%，流动比率 0.8x，速动比率 0.72x。净资产从 2021年 158.67亿缩水至 106.48亿。公司有现金，但负债高、流动性紧，抗风险能力不强。

**4. 当前价格的安全边际：1 / 5**  
当前 PB 3.69，显著高于同业；FCF×15 给出 19.84元，仍低于当前股价 20.31元。以相对保守的 FCF×10 口径看，安全边际为 -53.52%。当前价格没有安全边际。

**5. 综合判断：回避**  
公司营收回升但主业持续亏损，2026上半年经营现金流大幅转负，PB 远高于同业，自由现金流口径下内在价值低于当前股价。投资价值不具备。

**6. 巴菲特式追问**  
- **10年后这笔生意还在吗？** 可能还在，商用车制造不会消失，但它很可能仍需要大量资本开支，利润随周期大幅波动。  
- **若股市关闭五年，我愿不愿意以今天 20.31元的价格持有？** 不愿意。因为该公司尚未证明能以持续正向现金回报股东。

**7. 一句话结论**  
江淮汽车营收回升但主业连年亏损，2026上半年经营现金流 -52.88亿，PB 3.69高于同业，当前股价高于 FCF 估算区间上限，回避。
