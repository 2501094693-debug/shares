交叉验证：2026中报的营业总收入、归母净利润、营业利润在东方财富主要指标、利润表、业绩报表中均为 4.84亿、-1.34亿、-1.37亿，校验通过。〔来源：东财主要指标 / 利润表 / 业绩报表〕

### 解读：这份财报最重要的 3 个变化

**总体判断：低于趋势改善线。**

1. **2025年报营收反弹，但利润继续恶化——低于。**  
   2025年报营业总收入 17.45亿元，同比增长 8.87%；但营业利润为 -2.89亿元，归母净利润为 -2.88亿元，同比 -17.15%，亏损比 2024年的 -2.46亿元扩大约 0.42亿元。收入恢复增长完全没有转化为利润改善，这是“增收不增利”甚至“增收扩亏”。

2. **2026中报收入同比大幅下滑，亏损同比扩大——低于。**  
   2026中报营业总收入 4.84亿元，较 2025中报的 6.77亿元下降约 1.93亿元，同比约 -28.5%；归母净利润为 -1.34亿元，而 2025中报为 -4343.19万元，亏损同比扩大约 0.91亿元。也就是说，上半年收入少了近三成，亏损反而翻了两倍以上。

3. **经营现金流由正转负，但同比少流出——弱改善，仍偏空。**  
   2026中报经营现金流为 -2.53亿元，较 2025年报的 +1.84亿元明显转差；但较 2025中报的 -3.25亿元少流出约 0.72亿元，改善约 22.2%。这只能说是“失血速度略有放缓”，不是现金创造能力恢复。

### 解读：增长是在加速还是减速？利润质量如何？

**收入端：2025年出现了近年的首次反弹，但仍在低位。**  
营业总收入从 2021年的 31.43亿元一路降到 2024年的 16.03亿元，2025年回到 17.45亿元，同比 +8.87%。这个反弹是事实，但必须看到：17.45亿元只相当于 2021年 31.43亿元的约 55.5%，收入规模仍然处在五年低位附近。

**利润端：收入反弹没有修复利润，反而亏损扩大。**  
2021年归母净利润还是 +1.84亿元，2022年降至 +6604.25万元，2023年转亏为 -5.53亿元，2024年减亏至 -2.46亿元，2025年又扩大为 -2.88亿元，同比 -17.15%。注意：2024年的同比 +55.56% 是因为 2023年亏损更深，不是盈利恢复。2025年的 -17.15% 则意味着亏损重新扩大。扣非净利润 2024年、2025年均为 -3.01亿元，说明主业亏损没有实质收窄。

**利润质量：差。**  
2025年营业利润 -2.89亿元、利润总额 -2.87亿元、归母净利润 -2.88亿元，三者几乎一致，说明利润总额到归母净利润之间没有明显非经常性收益粉饰；扣非净利润为 -3.01亿元，也说明公司亏损主要来自经常性经营，不是一次性项目造成的“假亏”。这种亏损的质量很差，因为它会持续侵蚀净资产。

### 解读：高回报是否可持续？是定价权、周转还是杠杆？

**高回报不可持续，当前是资本回报为负的阶段。**  
ROE 从 2021年的 +6.98%、2022年的 +2.43%，转为 2023年的 -22.50%、2024年的 -12.06%、2025年的 -16.48%。2025年 ROE 比 2024年再恶化 4.42个百分点。也就是说，股东每投入 100元净资产，2025年亏损 16.48元，这已经不是回报高低问题，而是价值销毁。

**毛利率低位回升，但远不够覆盖费用。**  
2025年毛利率为 14.69%，较 2024年的 13.12%回升 1.57个百分点，但仍低于 2023年的 17.39%、2022年的 19.47%、2021年的 19.77%。净利率 -16.45%、经营利润率 -16.53%，均为负数。  
从利润表原始科目看，2025年营业成本 14.89亿元，毛利只有约 2.56亿元；而销售费用 7779.67万元、管理费用 2.13亿元、财务费用 4730.87万元，三项费用合计约 3.38亿元，仅三项费用就已经超过毛利润约 0.82亿元。再加上未在表格中单列的税金及附加、减值等，最终营业利润为 -2.89亿元。这清楚说明：公司的问题不在毛利率崩到无法挽回，而在收入规模无法覆盖刚性费用。

**不是定价权，也不是健康杠杆。**  
2025年 ROA 为 -4.83%、ROIC 为 -6.74%，均为负。ROE 为负的同时资产负债率高达 71.98%，说明较高的杠杆并没有带来正回报，反而在亏损阶段放大了对净资产的侵蚀。公司不具备可供验证的持续高回报特征。

### 解读：利润有没有变成现金？FCF 与 capex 说明公司在收缩还是扩张？

**2025年报层面：经营现金流是正的，但不足以改变全年亏损事实。**  
2025年经营现金流为 +1.84亿元，而净利润为 -2.88亿元。经营现金流为正，说明销售回款和营运资金变动带来了一定现金补偿。销售商品收现 19.97亿元，高于营业总收入 17.45亿元，收现比约为 1.14倍，回款表面不差。  
自由现金流表中 2025年报为 +8382.7万元，这是 2024年 -5958.91万元之后的转正。但要注意：表内 FCFF_BACK 与“经营现金流 1.84亿 − 购建固定资产 9039.59万”并不完全一致，直接相减约为 9360万元，与 8382.7万元存在约 977万元差异，说明该 FCF 为东财 FCFF_BACK 口径，不完全等同于简单经营现金流减资本开支。

**2026年中报层面：现金流转负，重新开始失血。**  
2026中报销售商品收现 5.3亿元，仍然高于营业总收入 4.84亿元，收现比约 1.10倍；但经营现金流为 -2.53亿元。也就是说，收入现金收到了，但公司对外支付、存货或应收占款更大，导致经营现金流大幅流出。  
简单估算，2026中报经营现金流 -2.53亿元，再减去购建固定资产 2387.42万元，自由现金流约为 -2.77亿元。这个数字不是资料表内直接披露的 FCF，而是按“经营现金流 − 购建固定资产”做的粗略估算，但方向很明确：上半年没有自由现金流创造能力。

**资本开支：规模在收缩，不是扩张。**  
资本开支从 2021年的 1.37亿元、2022年的 1.51亿元，降到 2025年的 9039.59万元；2026中报购建固定资产仅 2387.42万元。资本开支绝对额在下降，结合营业总收入从 2021年 31.43亿元收缩至 2025年 17.45亿元，公司整体处于收入收缩、资本开支收缩的状态，而不是扩张期。

**现金安全性：2026上半年净消耗速度较快。**  
2026中报现金净增加为 -2.94亿元，而 2025年末货币资金为 5.39亿元。若粗略以现金净增加对应货币资金消耗，-2.94亿元约相当于 2025年末货币资金的 54.5%。但 2026中报资产负债表货币资金未在已给资料中列出，因此不能直接得出期末货币资金余额，只能提示失血速度较快。

### 解读：现金储备、资产负债率、流动/速动比率、应收与存货有无恶化

**负债率持续上升，净资产被不断侵蚀。**  
资产负债率从 2021年的 64.56%升至 2025年的 71.98%，五年内上升约 7.42个百分点。净资产从 2021年的 27.29亿元逐年下降至 2025年的 16.35亿元，五年减少约 10.94亿元。这不是因为分红或回购，而是连续大额亏损直接消耗了家底。

**短期流动性变弱。**  
流动比率从 2021年的 1.3x 降至 2025年的 1.14x；速动比率从 0.88x 降至 0.82x。速动比率低于 1，意味着剔除存货后，流动资产不足以覆盖流动负债，短期偿债安全垫比较薄。  
另外，短期借款在原始资料中显示为“—”，公开资料未披露具体余额，不能据此判断有息负债为零，只能说从已给数据无法准确拆出短期有息负债。

**应收和存货绝对额高，资金占用严重。**  
2025年应收为 19.3亿元，而当年营业总收入为 17.45亿元，应收/营收约为 1.11倍；存货为 11.01亿元，约为营业总收入的 63.1%。应收加存货合计约 30.31亿元，占 2025年总资产 58.35亿元的约 51.9%。资产端超过一半被应收和存货占用，营运资金质量较差。

**现金有一定缓冲，但2026年上半年消耗较快。**  
2025年末货币资金 5.39亿元，较 2024年末的 4.51亿元增加 0.88亿元；但 2026中报现金净增加为 -2.94亿元，若这种流出节奏延续，现金缓冲会被快速消耗。

**PS 也高于历史中位。**  
当前 PS_TTM 为 3.26，历史 PS_TTM 中位为 2.4。也就是说，按收入估值，当前比长期中位数高出约 35.8%。公司收入只有 2021年的约 55.5%，但市销率仍高于自身历史中位，说明收入规模收缩时市场给的单位收入估值并不低。

**相对同业：亏损更深，PB 却不便宜。**  
本公司 ROE 为 -8.69%，PB 为 3.45。同业中，中航光电 ROE 为 4.61%，PB 只有 2.94；本公司 PB 比中航光电更高，但盈利能力显著更差。亏损同业景嘉微 ROE 为 -1.58%，PB 为 3.81；本公司 ROE 为 -8.69%，亏损更深，PB 仅比景嘉微低 0.36倍。就 PB-ROE 组合而言，四创电子并不具备吸引力。

**EV 粗算放大估值的“贵”。**  
EV = 市值 50.68亿 + 总负债 42亿 − 货币资金 5.39亿 = 87.29亿元。这意味着把负债算进去后，企业价值远超市值。公司 2025年营业总收入 17.45亿元，对应 EV/收入 约 5.0倍；而 2025年归母净利润为 -2.88亿元，EV 相对亏损没有正向回报支撑。

## 七、安全边际：内在价值 vs 当前股价

### 原始数据：安全边际预计算

| 估算项 | 数值 | 口径 |
|---|---|---|
| 当前股价 | 18.84 | 东财盘口 |
| 总市值 | 50.68亿 | 股价×总股本 |
| EV（粗算） | 87.29亿 | 市值+总负债-货币资金 |
| PE_TTM | -13.4 | 盘口 |
| PB | 3.45 | 盘口 |
| PS_TTM | 3.26 | 盘口 |
| FCF Yield | 1.65% | 最近年报FCF/市值 |
| 历史PE中位 | 43.85 | 东财日频估值序列 |
| 内在价值A | -21.79 | EPS×历史PE中位 |
| 安全边际A | 186.46% | (IV-股价)/IV |
| 内在价值B | 3.12 | 每股FCF×10 |
| 内在价值C | 4.67 | 每股FCF×15 |
| 安全边际B | -504.60% | 对应FCF×10 |

〔来源：东财盘口 / 东财估值分析明细 / 安全边际预计算〕

### 解读：你认同哪一种口径、假设是什么、安全边际是否足够

**PE 法不可用。**  
“内在价值A = EPS × 历史PE中位”的结果为 -21.79元/股。用盘口每股收益 -0.497元乘以历史 PE 中位 43.85，得到负的内在价值，说明亏损状态下不能机械套用 PE 估值。这个口径应当放弃。

**FCF 倍数法最接近巴菲特“自由现金流折现”的简化思路，但可靠性有限。**  
2025年报自由现金流为 8382.7万元，对应每股自由现金流约 0.312元。  
- 每股FCF × 10 = 3.12元  
- 每股FCF × 15 = 4.67元  

当前股价 18.84元，远高于 3.12—4.67元区间。若以 10倍口径计算，安全边际为 -504.60%，意味着股价约为该口径内在价值的 5倍以上。  
但必须强调：这个口径假设 2025年报的自由现金流可以持续。实际上 2026中报经营现金流为 -2.53亿元，再减购建固定资产 2387.42万元后，上半年自由现金流约为 -2.77亿元。因此 2025年的正自由现金流很可能不可持续，FCF 倍数法给出的 3.12—4.67元可能还偏乐观。

**PB 历史分位法可作为辅助参考。**  
盘口每股净资产为 5.43元。  
- 按历史 PB 中位 2.67：5.43 × 2.67 ≈ 14.5元  
- 按历史 PB 最低 1.44：5.43 × 1.44 ≈ 7.8元  

当前股价 18.84元对应 PB 3.45，高于历史中位。换句话说，即便只是回到历史中位 PB，股价也应向 14.5元附近收敛；若回到历史低位，则要到 7.8元附近。

**明确区间：当前价格没有安全边际。**  
综合上述可验证口径：  
- 保守现金流估值区间：约 **3.1—4.7元/股**  
- 资产估值辅助区间：约 **7.8—14.5元/股**  

当前股价 18.84元高于上述区间。若以 FCF 法看，股价需要跌到 3—5元才具备较强现金回报安全边际；若以 PB 历史中位看，至少也要回到 14—15元以下才回到历史中枢。因此，18.84元不构成安全边际。

## 八、巴菲特视角评估（结论）

| 评估项 | 得分（1—5） | 依据 |
|---|---|---|
| 生意可理解性 | 2/5 | 军工电子生意表面可理解，但利润与现金流链条不稳定：2025年报销售收现 19.97亿、经营现金流 +1.84亿；2026中报销售收现 5.3亿、经营现金流 -2.53亿，现金创造波动极大。 |
| 财务质量与护城河证据 | 1/5 | 2025年报毛利率 14.69%、ROE -16.48%、净利率 -16.45%；近五年仅 2021—2022年 ROE 为正，2023年起连续亏损，不具备持续高回报证据。 |
| 资产负债表与“活下去”能力 | 2/5 | 2025年资产负债率 71.98%，速动比率 0.82x，货币资金 5.39亿；应收+存货占总资产约 51.9%；2026中报现金净减少 2.94亿，短期安全垫不厚。 |
| 当前价格的安全边际 | 1/5 | PB 3.45，高于历史中位 2.67；FCF Yield 仅 1.65%；FCF 法内在价值约 3.1—4.7元/股，远低于 18.84元。 |

**综合判断：回避。**  
这不是“值得进一步研究”的阶段，也不是“再等等就能买”的情形，而是盈利、现金流、资产负债表三者同时走弱，且股价仍在历史 PB 中位之上。

**巴菲特式追问：**

- **10年后这笔生意还在吗？**  
  可能还在，因为它处于军工电子领域，产品或系统有长期需求。但“生意还在”不等于“股东回报还在”。近五年 ROE 从 +6.98% 跌到 -16.48%，若这种资本回报持续，10年后公司可能仍在，但股东价值会被继续侵蚀。

- **若股市关闭五年，你愿不愿意以今天的价格持有？**  
  不愿意。以 18.84元买入，按 2025年报自由现金流计算的 FCF Yield 只有 1.65%；而 2026中报经营现金流为 -2.53亿元，自由现金流估算为负。股市关闭五年，没有流动性溢价，只能靠公司内生现金回报，而这家公司当前没有提供足够回报。

**一句话结论：**  
四创电子2026中报营收4.84亿、归母净利-1.34亿，经营现金流-2.53亿；2025年报ROE -16.48%，当前PB 3.45高于历史中位，18.84元无安全边际，回避。
