### 一、这家公司做什么（一句话本质 + 用户/客户价值）

四创电子做的是一门“探测感知”的军工电子生意：把雷达整机、印制电路板/微波组件/电源等硬件，以及安防、应急、军队信息化、低空安全等系统集成，卖给气象、民航、公安、应急、军队等政府和军方客户，靠招投标、型号配套和项目验收赚钱。它不是平台，也不靠订阅，主要靠一个个项目制订单赚钱。〔来源：2025年年报 PDF 正文·第三节管理层讨论与分析；2026年半年度报告 PDF 正文·第三节管理层讨论与分析〕

对直接客户来说，气象局买的是台风、暴雨、雷暴等天气的探测与预警能力；民航和空管部门买的是机场终端区、航路和场面的监视安全；公安、应急、军队买的是要地防护、反无人机、应急指挥、低空监管等“看得见、防得住”的能力；军工装备总体单位买的是自主可控、能过型号认证的雷达配套件、微波组件、特种电源和印制电路板。客户愿意付钱，核心是因为公司有军民资质、有国产化产品谱系，能进入政府/军方的合格供应商体系并完成定制交付。〔来源：2025年年报 PDF 正文·第三节管理层讨论与分析〕

渠道和合作方价值上，公司长期与中国气象局、中国民航、中国水利、各军种及科研院所保持客户关系；中电博微作为控股股东、中国电科作为实际控制人，提供了军工央企背景和体系内协同入口。终端用户价值更直接：机场方获得空管监视保障，城市管理者获得低空安全防控，应急部队获得“三断”情况下的通信指挥能力。〔来源：2025年年报 PDF 正文·第三节管理层讨论与分析；2026年第一季度报告 PDF 正文·股东信息〕

### 二、商业模式本质与收入结构

这门生意最贴切的定义是“项目制装备销售 + 系统集成”，不是复购、订阅或平台抽成。雷达整机、公共安全系统、低空安全项目大多是定制化、按合同研制或建设、验收后确认收入；印制电路板、电源产品虽然单品可重复销售，但客户仍以军工、航空航天、高端装备为主，订单节奏受型号和项目影响很大。因此收入有明显波动性，2026年上半年公司自己解释收入下降是“合同支撑不足所致”。〔来源：2025年年报 PDF 正文·第三节管理层讨论与分析；2026年半年度报告 PDF 正文·第三节管理层讨论与分析〕

### 三、飞轮如何运转

公开资料看不到平台型网络飞轮，它更接近一个政府/军工项目制的“增长循环”：依靠资质和技术进入客户体系 → 中标或承接型号/项目 → 完成定制研制和交付 → 形成标杆工程和客户信任 → 再拿同体系后续订单或向新场景扩品。年报中“合肥市低空经济基础设施项目（一期）”就是一个典型：公司先中标超亿元项目，再据此形成低空安全整体解决方案，进而参与标准规范制定、复制到其他场景。〔来源：2025年年报 PDF 正文·第三节管理层讨论与分析·经营情况讨论与分析〕

但这个循环目前并没有稳定转起来。2026年一季度营业收入同比下降41.86%，公司解释是“雷达整机收入同比减少”；2026年上半年营业收入同比下降28.50%，公司解释是“合同支撑不足”。同时，低空安全等新业务还处在高研发投入、尚未规模化盈利阶段。也就是说，低空经济的新循环刚开始画，传统雷达项目制循环又出现订单波动，整体增长循环尚未被持续验证。〔来源：2026年第一季度报告 PDF 正文·主要财务数据；2026年半年度报告 PDF 正文·第三节管理层讨论与分析·经营情况的讨论与分析〕

### 四、护城河逐项验证

**品牌/定价权：部分成立，但偏弱。** 公司有气象雷达、空管雷达、低空雷达等较全产品谱系，客户序列较高，品牌在政府和军方客户中有一定认知。但年报自己承认空管雷达“国内市场上相互之间竞争较为激烈”，感知应用业务毛利率只有3.83%，说明系统集成类订单定价权不强，很多业务赚的是辛苦钱。〔来源：2025年年报 PDF 正文·第三节管理层讨论与分析·所处行业情况及主营业务分析〕

**转换成本：部分成立。** 雷达整机、军用型号、民航监视设备、气象专用装备一旦进入客户体系，后续改型、备件、维护和系统扩容有延续性，切换成本高于一般工业品。但电源、印制电路板等感知基础业务，客户可选供应商较多，军工航天领域之外的可替换性并不低。〔来源：2025年年报 PDF 正文·第三节管理层讨论与分析·核心竞争力分析〕

**网络效应：不成立。** 这门生意的价值不随用户数量增加而上升，雷达和系统集成项目之间也没有用户之间的正反馈，公开资料看不到任何网络效应。〔来源：2025年年报 PDF 正文·第三节管理层讨论与分析〕

**规模效应：部分成立，但当前不明显。** 雷达整机多品种、小批量，定制程度高，规模摊薄有限；印制电路板、电源制造理论上可通过自动化产线降本，公司也提到华耀电子中大功率电源自动化生产线达产、提升生产效率。但2026年上半年收入大幅下降、研发费用却大增，说明当前规模效应还不足以平滑收入波动。〔来源：2025年年报 PDF 正文·第三节管理层讨论与分析；2026年半年度报告 PDF 正文·第三节管理层讨论与分析〕

**技术/工艺/资质壁垒：成立。** 这是公司最实的护城河。公司拥有民用航空空中交通通信导航监视设备使用许可证多类、多款气象专用技术装备使用许可证、电子与智能化工程专业承包一级、CMMI5等；2025年研发投入强度13.80%，累计拥有发明专利350余件，连续9年入围安徽省发明专利排行榜；2026年上半年研发投入强度进一步提高到14.98%。这些资质和型号认证不是短期能复制出来的。〔来源：2025年年报 PDF 正文·第三节管理层讨论与分析·核心竞争力分析；2026年半年度报告 PDF 正文·经营情况讨论与分析〕

总体看，护城河宽度中等：资质和技术壁垒真实，但定价权和盈利质量弱，商业化转化不稳定。近一年公司在低空安全产品、许可证、地方标准上有所加宽，但传统感知产品收入下滑、整体亏损扩大、经营现金流为负，护城河没有在财务上体现为变宽。〔来源：2025年年报 PDF 正文；2026年半年度报告 PDF 正文〕

### 五、业务矩阵与协同效应

公司业务可以概括为“一核两翼新动能”：核心是雷达整机及探测感知产品，两翼是感知基础（PCB、微波、电源）和感知应用（安防、应急、军队信息化），低空经济是战略新动能。协同确实存在：印制电路板、微波组件、电源可以为雷达整机和星载重大项目配套；低空安全业务复用气象雷达、空管雷达的探测技术和政府/公安客户关系。年报也显示，感知基础领域中标了星载多功能板、八通道微波组件、功分馈电模块等配套项目，说明业务之间有技术同源性。〔来源：2025年年报 PDF 正文·第三节管理层讨论与分析；2026年半年度报告 PDF 正文·第三节管理层讨论与分析〕

但协同没有充分转化为利润。感知应用业务收入规模不小，但毛利率只有3.83%，说明系统集成吃掉大量成本；雷达及雷达配套毛利率也只有16.76%。低空经济方面，合肥项目、低空监视雷达、低空大模型、低空微气象系统等新动作，方向上是加强主业，没有明显证据显示是分散精力，但这些新业务仍处在研发投入期，尚未形成规模化盈利贡献。〔来源：2025年年报 PDF 正文·主营业务分析；2026年半年度报告 PDF 正文·经营情况讨论与分析·可能面对的风险〕

### 七、段永平视角：这是不是一门好生意

哈，这门生意我大致看得懂：给政府和军队做雷达、做配套、做系统集成。但看得懂产品，不等于看得懂它十年后能不能稳稳地赚钱。它赚的是项目钱，订单和回款都捏在财政预算和验收节奏手里，现金流容易一抖一抖的。〔来源：2025年年报；2026年半年度报告〕

差异化有一点，气象雷达、空管雷达、低空安全那些牌照和技术不是谁都能做，这算是差异化。但差异化没有强到能随便涨价，公共安全业务毛利率只有3.83%，整体毛利率也就14%出头，说明很多单子是拼出来的。定价权弱，政府客户不会让你赚高毛利。〔来源：2025年年报〕

护城河呢，资质和技术是真的，但低空业务还在烧钱，传统雷达收入还下滑，研发费用动不动翻倍。这种生意要不断靠研发投入和项目抢单来维持，不太像那种躺着就能把护城河越挖越宽的生意。公司当然是在做本分的事，国产化、安全、防务，都是围着用户转，但“本分”和“好生意”是两码事。〔来源：2025年年报；2026年半年度报告〕

综合判断：**辛苦的生意**。

一句话：有牌照、有技术，但客户强势、回款慢、利润薄，赚的是本分但辛苦的钱。〔来源：2025年年报；2026年半年度报告〕
