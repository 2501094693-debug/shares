### 解读

1. 按预计算口径，公司属于**混合型**。2026中报经营性资产 **2413.94亿**、占比 **63.50%**，投资性资产 **527.92亿**、占比 **13.89%**，经营性资产约为投资性资产的 **4.57倍**，经营主导特征明确；但投资性资产绝对额达 **527.92亿**，且商誉就有 **242.81亿**，说明公司在主业之外保留了较大规模的投资性布局。战略意图可概括为：以动力系统主业经营为基本盘，同时借助投资性资产布局产业链协同与国际化，形成“经营为本、投资协同”的混合型战略。

2. 同口径半年报看，经营性资产占比从2022中报 **71.68%**、2023中报 **71.76%** 回落至2025中报 **62.84%**，2026中报小幅回升至 **63.50%**；投资性资产占比由2020中报 **16.16%**、2022中报 **15.77%** 降至2026中报 **13.89%**，2026中报较2025中报 **14.44%** 下降 **0.55个百分点**。绝对额上，2026中报经营性资产 **2413.94亿**，较2025中报 **2295.69亿** 增加 **118.25亿**；投资性资产 **527.92亿** 较2025中报 **527.61亿** 仅增加 **0.31亿**。趋势为：经营资产仍是扩张主力，投资资产基本稳定，经营占比自2022—2023年高位回落后，近两年在 **63%** 附近企稳。

3. 从“投资性资产”口径（含长期股权投资、商誉等）看，未观察到控制性投资明显扩张。2026中报投资性资产 **527.92亿**，与2025中报 **527.61亿** 基本持平；商誉2026中报 **242.81亿**，较2025中报 **255.98亿** 减少 **13.17亿**，较2024中报 **246.11亿** 减少 **3.30亿**。投资性资产总额持平、商誉高位回落，说明长期股权投资、商誉等并未形成新一轮控制性投资扩张。

4. 按“重资产指数=固定资产÷总资产”口径，2026中报固定资产 **525.86亿**、总资产 **3801.64亿**，重资产指数为 **13.83%**，低于 **20%**，不属于典型重资产。同期货币资金达 **775.43亿**，应收和存货两金合计 **800.35亿**、占总资产 **21.05%**，资产更多沉淀在经营周转环节，呈现“运营资金密集型”特征。固定资产较2025中报 **509.01亿** 增加 **16.85亿**，占比基本持平，配置相对克制；结合存货周转天数 **148天**、应收周转天数 **121天**，资产效率压力更集中在运营资金而非固定资产端，固定资产占比本身处于相对合理区间。

### 本章小结

2026中报潍柴动力呈经营为主、投资为辅的混合型资产结构，经营性资产占 **63.50%**、投资性资产占 **13.89%**，战略以主业经营为基本盘、以投资性资产做协同；固定资产占 **13.83%** 偏轻资产，控制性投资未明显扩张，但两金合计 **800.35亿**、占比 **21.05%**，运营资金占用较重，需重点关注周转效率。

**计算公式**

| 指标 | 计算公式 |
|---|---|
| 两头吃指数 | (应付账款 + 预收款项/合同负债) ÷ (应收账款 + 预付款项)；>1 表示对上下游占款能力强 |
| 存货周转天数 | 365 × 存货 ÷ 营业成本 |
| 应收周转天数 | 365 × 应收账款 ÷ 营业收入 |

### 解读

1. 两头吃指数反映的上下游议价能力：2026中报两头吃指数为 **2.10x**，公式含义为（应付账款+预收款项/合同负债）÷（应收账款+预付款项），大于1表示企业占用上下游资金能力强。**2.10x** 说明潍柴动力在产业链中仍保持较强话语权；但同口径同比看，该指标自2024中报 **2.41x**、2023中报 **2.51x** 以来连续回落，2026中报虽高于2025中报的 **1.84x**，但尚未回到此前高位，反映上下游占款能力边际改善但仍弱于2024年中报同期。

2. 存货周转天数、应收周转天数的变化及含义：存货周转天数=365×存货÷营业成本，应收周转天数=365×应收账款÷营业收入，均为按半年报累计数×365估算，会偏高。2026中报存货周转天数为 **148天**，较2025中报 **152天** 小幅缩短，存货周转效率略有改善；应收周转天数为 **121天**，较2025中报 **128天** 缩短7天，回款效率有所提升，但仍显著高于2024中报 **101天**、2023中报 **94天**，应收账款占用仍处相对偏高水平。需注意2022中报存货周转天数 **18天**、2020中报 **13天** 数值异常偏小，主要受半年报累计口径及当时营业成本与存货规模匹配影响，不具直接可比性。

3. 固定资产周转效率：固定资产周转=营业收入÷固定资产。2026中报固定资产周转为 **2.34x**，较2025中报 **2.22x** 略有提升，同比改善约0.12次。但从中报同口径趋势看，该指标已明显低于2021中报 **4.19x**、2019中报 **3.93x**、2020中报 **3.25x**，说明固定资产规模扩张后，单位固定资产创造营业收入的效率较早期明显下降，需结合重资产指数13.83%判断并不算高，但产能释放效率仍需关注。

4. 两金（应收+存货）是否存在积压风险：两金绝对值数据未披露，但从周转天数间接观察，2026中报存货周转天数 **148天**、应收周转天数 **121天**，二者合计占用约256天，显著高于2024中报合计254天、2023中报合计250天，应收端占用天数整体偏高，存在一定资金占用压力。存货周转天数近年来基本维持在 **148-156天** 区间，相对稳定；应收账款周转天数从2023中报 **94天** 升至2026中报 **121天**，抬升更明显，提示应收端占用风险大于存货端，需关注回款质量及下游信用政策变化。

### 本章小结

潍柴动力2026中报两头吃指数 **2.10x** 显示其对上下游仍保持较强占款能力，但该优势较2024年中报高峰有所弱化；存货周转小幅改善、应收周转较2025中报加快，但应收端占用天数自2023中报以来明显抬升，两金整体仍存在一定积压和回款压力。

### 解读

1. 2026中报（1—6月累计口径）核心利润为 **98.1亿元**，核心利润率为 **7.97%**。该指标按“营业收入−营业成本−税金及附加−销售/管理/研发/财务费用”计算，反映主业经营盈利。与2025中报同口径相比，核心利润由 **76.21亿元** 增至 **98.1亿元**，核心利润率由 **6.74%** 提升至 **7.97%**，同比提高 **1.23个百分点**，主业盈利规模与效率均改善。

2. 2026中报归母净利润为 **77.01亿元**，扣非净利润为 **61.19亿元**，扣非占比为 **79.45%**；两者差额 **15.82亿元**，约占归母净利润 **20.55%**，非经常性项目贡献上升。2025中报扣非占比为 **91.22%**，2024中报为 **92.81%**，2026中报同比下降 **11.77个百分点**，利润成色弱于前两年。表列非核心损益“归母净利润−核心利润”为 **-21.09亿元**，说明非核心项目整体对归母净利润形成侵蚀，核心利润高于归母净利润。

3. 2026中报营业收入为 **1231.63亿元**，较2025中报 **1131.52亿元** 增长约 **8.85%**；同期核心利润由 **76.21亿元** 增至 **98.1亿元**，增长约 **28.72%**，核心利润增速高于营收增速约 **19.87个百分点**。核心利润率由 **6.74%** 提升至 **7.97%**，说明核心利润增长并非单纯依赖收入规模扩张，费用、税金及其他经营支出占收比下降亦有贡献，营收与核心利润匹配度良好。

4. 2026中报毛利率为 **21.46%**，较2025中报 **22.18%** 下降 **0.72个百分点**；2024中报为 **21.75%**，2023中报为 **18.80%**，2022中报为 **17.73%**。毛利率自2022—2023年低点回升后，2025中报达到近年同期高点 **22.18%**，2026中报虽有所回落，但仍高于2023中报 **2.66个百分点**、高于2022中报 **3.73个百分点**，整体呈修复后的高位波动。

### 本章小结

2026中报核心利润和核心利润率同比明显提升，核心利润增速快于营收增速，主业经营效益改善；但毛利率同比回落，扣非占比降至 **79.45%**，非经常性项目贡献上升，利润成色弱于上年同期。

### 解读

1. 2026中报ROE为 **8.00%**，ROA为 **2.55%**，ROIC为 **5.47%**。与2025中报同口径相比，ROE上升 **1.71个百分点**、ROA上升 **0.70个百分点**、ROIC上升 **1.55个百分点**，三项指标均同比改善。拉长同口径中报序列看，2022中报为阶段低点，ROE **3.28%**、ROA **1.01%**、ROIC **1.70%**，此后逐年修复；但当前仍未回到历史高位，2021中报ROE为 **11.18%**、ROA为 **2.98%**、ROIC为 **6.19%**，2019中报ROE **12.49%**、ROA **3.15%**、ROIC **6.55%**，均明显高于2026中报。上述指标为半年报累计口径，未年化，不可与年报直接横比，同比仅采用同口径中报数据。

2. 2026中报的杜邦拆解为：净利率 **7.75%**、资产周转 **0.32x**、权益乘数 **2.82x**。与2025中报相比，净利率上升 **1.95个百分点**，资产周转上升 **0.01x**，权益乘数下降 **0.07x**，因此本期ROE回升的主要驱动力是净利率改善，而非周转和杠杆。权益乘数按总资产÷净资产计算，反映财务杠杆；资产周转按营业收入÷总资产计算，且为半年累计口径，0.32x未年化，同口径下仅作趋势比较。与高点的2021中报相比，2021中报净利率 **6.34%**、资产周转 **0.44x**、权益乘数 **3.01x**，当时ROE达到 **11.18%**；当前净利率虽更高，但资产周转低 **0.12x**、权益乘数低 **0.19x**，导致ROE仍低于2021中报。

3. 2026中报归母净利润为 **77.01亿**，净资产为 **1350.01亿**；2025中报归母净利润为 **56.43亿**，净资产为 **1262.89亿**。净资产同比增加 **87.12亿**，2026中报归母净利润相当于该净增加额的 **88.4%**，粗略显示利润积累是净资产增长的主要来源。但需注意口径不完全匹配：归母净利润为2026上半年累计数，净资产增量为2025中报至2026中报的跨期变化。进一步看，归母净利润同比增速为（77.01÷56.43-1）×100%= **36.5%**，净资产同比增速为（1350.01÷1262.89-1）×100%= **6.9%**，利润增速显著高于净资产增速，也支持利润积累主导净资产增长的判断。

4. 同业对照表中，潍柴动力ROE为 **8.14%**，高于全部列示的同业公司，例如伯特利 **7.81%**、万向钱潮 **6.51%**、银轮股份 **6.08%**、双环传动 **5.75%**、拓普集团 **4.23%**、斯菱智驱 **4.21%**、飞龙股份 **2.22%**、山子高科 **1.07%**，显示股东回报能力在同业中处于领先。估值方面，潍柴动力PE_TTM为 **18.11**、PB为 **2.45**，低于拓普集团PE **31.2**、万向钱潮 **34.66**、银轮股份 **34.43**等，也低于ROE接近的伯特利PB **3.1**，相对估值并未明显高估。ROA、ROIC的同业对照数据未披露。

### 本章小结

2026中报价值创造能力同比回升，ROE、ROA、ROIC均改善，但仍低于2021年和2019年同期高点；ROE改善主要由净利率驱动，资产周转和权益乘数贡献有限。利润积累是净资产增长的主要来源，ROE在同业对照中领先且估值相对不高。

2. 2026中报研发费用率为 **3.23%**，较2025中报的 **3.65%** 下降 **0.42个百分点**。从近八年中报序列看，该水平低于2022中报的 **4.25%**、2024中报的 **3.82%**、2023中报的 **3.51%**，但高于2019中报的 **2.64%**、2020中报的 **2.73%**、2021中报的 **2.81%**。研发费用率回落表明在营业收入规模扩大的背景下，研发投入强度未同步提升；但表中未披露研发费用绝对金额，不能据此判断研发支出绝对额下降。

4. 2026中报毛利率为 **21.46%**，较2025中报的 **22.18%** 下降 **0.72个百分点**；按“销售费用率+管理费用率+研发费用率+财务费用率”计算，期间费用率合计由 **15.09%** 降至 **13.10%**，下降约 **1.99个百分点**。其中销售费用率和管理费用率合计下降 **2.50个百分点**，研发费用率下降 **0.42个百分点**，财务费用率上升 **0.93个百分点**。毛利率与费用率呈反向联动：毛利率下滑对利润形成负向拉动，但期间费用率压降幅度大于毛利率降幅，费用管控在一定程度上对冲了毛利下滑的影响，利润弹性主要来自费用压缩而非毛利率改善。

### 本章小结

2026中报成本决定机制表现为“营业成本率小幅上升、毛利率下滑、期间费用率总体下降”，成本改善主要依赖管理费用和销售费用的决策性压缩。研发费用率回落显示技术投入强度边际减弱，而财务费用率由负转正成为利润端的主要侵蚀因素之一。

3. 经营现金流对核心利润的验证：

- 战略一致性：混合型且经营主导，经营资产 **2413.94亿**、占比 **63.50%**，投资性资产 **527.92亿**、占比 **13.89%**，经营/投资 **4.57倍**；投资性资产同比仅增 **0.31亿**，控制性投资未明显扩张，战略未漂移。

- 资产质量：差。两金合计 **800.35亿**、占总资产 **21.05%**，应收周转 **121天**、存货周转 **148天**；商誉 **242.81亿**、占投资性资产 **45.99%**；固定资产/总资产 **13.83%**虽偏轻，但资产压力集中在经营周转和商誉。
- 偿债安全：资产负债率 **83.34%**偏高；金融性负债 **325.11亿**、占负债 **13.26%**，经营性负债 **1529.76亿**、占负债 **62.40%**，刚性有息负债占比低；但货币资金 **775.43亿**与规则提示的“短期借款较高”构成存贷双高迹象，需关注短债到期与资金受限。
- 增长可持续性：核心利润 **98.1亿**、同比增 **28.72%**，快于营收 **8.85%**，核心利润率 **7.97%**改善，ROE **8.00%**同比上升；但毛利率 **21.46%**同比降 **0.72个百分点**、研发费用率 **3.23%**降 **0.42个百分点**、购建固定资产 **24.85亿**同比降 **28.3%**，当前增长更依赖费用压降和营运资金扩张，持续性需观察。

4. 后续跟踪建议：
- 两金及周转：当前两金合计 **800.35亿**、占总资产 **21.05%**，应收/存货周转天数 **121天/148天**，若继续上升将加重资金占用，是资产质量核心指标。
- 两头吃指数：当前 **2.10x**，公式为（应付账款+预收款项/合同负债）÷（应收账款+预付款项），需观察能否回到2024中报 **2.41x**、2023中报 **2.51x**，验证议价能力是否趋势性修复。
- 经营现金流/核心利润：当前 **115.69%**，若持续低于100%将弱化利润现金保障，应结合销售收现比 **105.63%**持续跟踪。
- 毛利率与扣非占比：当前毛利率 **21.46%**、扣非占比 **79.45%**，关注成本刚性和非经常损益对归母净利的影响。
- 商誉减值：商誉 **242.81亿**、占投资性资产 **45.99%**，需跟踪减值测试及并购标的盈利兑现，防范利润冲击。

### 本章小结

潍柴动力2026中报战略以经营为主导、现金流对利润支撑扎实，主业盈利改善与产业链议价能力是主要亮点；但两金占用偏高、商誉占比大、杠杆率较高，资产质量隐患尚未消除。后续应重点验证营运资金周转和商誉质量，而非仅看利润增速。
