〔来源：东方财富 F10 · 利润表 / 现金流量表〕

### 解读：这份财报最重要的 3 个变化

**1. 收入端由“停滞”转为“负增长”——低于预期。**  
2026中报营业总收入为 **56.15亿**，相比2025中报 **58.15亿** 减少 **2.00亿**，同比下滑 **3.44%**。这不是单季波动，而是上半年累计口径下的收入收缩。2025中报收入还有58.15亿，2026中报回落到56.15亿，说明公司收入端在近一年窗口内没有企稳，反而继续承压。

**2. 归母净利润同步下滑，但降幅小于营业利润——利润端“靠税负缓冲”，质量需打折。**  
2026中报归母净利润 **9.46亿**，比2025中报 **9.80亿** 减少 **0.34亿**，降幅 **3.47%**；但营业利润从 **12.04亿** 降至 **11.22亿**，降幅达到 **6.81%**。利润总额从 **12.29亿** 降至 **11.23亿**，降幅约 **8.6%**，而归母净利润只降3.47%，主要因为所得税从2025中报 **2.12亿** 降至2026中报 **1.51亿**，减少 **0.61亿**。因此，2026上半年归母利润的韧性有一定税负下降因素，不能全部理解为经营改善。

**3. 经营现金流走弱，回款并未改善——低于预期。**  
2026中报经营现金流 **6.21亿**，较2025中报 **6.77亿** 减少 **0.56亿**，同比下滑 **8.27%**。销售商品收到的现金为 **48.18亿**，低于2025中报 **49.48亿**。以“销售商品收现 / 营业总收入”衡量，2026中报约为 **85.8%**，与2025中报约 **85.1%** 基本持平，没有明显恶化，但也未改善。收入下滑叠加现金回款比例平稳，结果是经营现金流绝对额继续走低。

整体判断：**近一年财报偏低于预期**。收入、归母利润、经营现金流三项核心指标均低于上年同期，且归母利润的部分韧性来自所得税下降，并非纯粹的经常性经营改善。

### 解读：增长在减速，利润质量在改善，但收入端已连续两年负增长

**增长已经明显减速。** 2021年营业总收入 **91.12亿**，2022年 **96.25亿**，同比增长 **5.64%**；2023年冲到 **113.10亿**，同比增长 **17.50%**，是最近5年的收入高峰。但2024年回落到 **112.12亿**，同比 **-0.87%**；2025年进一步降至 **110.01亿**，同比 **-1.88%**。也就是说，2023年之后收入连续两年负增长。再叠加2026中报收入同比 **-3.44%**，收入端不是“高位平台整理”，而是持续小幅下行。

**利润端比收入端更有韧性。** 2025年报营业利润 **18.55亿**，相比2024年 **18.34亿** 微增 **1.15%**；归母净利润 **16.47亿**，相比2024年 **16.28亿** 增长 **1.18%**。虽然增速很低，但在收入下滑1.88%的情况下，利润没有同步下降，说明成本或费用控制起到了一定作用。

**经常性利润质量在提升。** 2023年归母净利润 **16.70亿**，但扣非净利润只有 **12.33亿**，差额高达 **4.37亿**，说明当年有较多非经常性收益。2024年扣非 **14.32亿**，2025年扣非 **15.68亿**，2025年扣非净利润同比增长约 **9.50%**，高于归母净利润1.18%的增速。2025年归母与扣非差额缩小至 **0.79亿**，利润更实。

结论：**增长在减速，但利润质量没有同步恶化；主要矛盾是收入端持续收缩，而不是利润表失控。**

〔来源：东方财富 F10 · 盈利能力指标〕

### 解读：高回报有证据，但更多来自利润率改善，而非收入增长驱动

**毛利率持续小幅上行。** 从2021年 **55.77%** 提升至2025年 **58.01%**，四年提升约 **2.24个百分点**。2026中报根据利润表计算，营业成本 **23.53亿**、营业总收入 **56.15亿**，对应毛利率约 **58.09%**，与2025年报 **58.01%** 基本持平。这说明公司产品结构或成本端有一定稳定性，但毛利率提升幅度并不算大。

**净利率和经营利润率提升更明显。** 净利率从2021年 **10.67%** 提高到2025年 **15.30%**；经营利润率从 **12.48%** 提高到 **16.86%**。费用率下降是重要原因：2025年报销售费用 **30.53亿**，占营收 **110.01亿** 约 **27.75%**；2026中报销售费用 **14.14亿**，占营收 **56.15亿** 约 **25.18%**，较2025中报销售费用率约 **26.35%** 有所下降。因此，利润率提升部分来自费用压缩，而非单纯由毛利率拉动。

**ROE和ROIC处于中高水平，但并不惊艳。** 2025年报ROE **14.86%**，比2024年 **15.07%** 微降 **0.21个百分点**；ROIC **12.86%**，也低于2023年 **13.03%**。ROA **9.88%**，与ROE之间的差距不大，主要因为公司负债率低。2025年资产负债率 **26.62%**，权益乘数不高，因此ROE并非靠高杠杆堆出来。这个ROE水平在化学制剂行业中属于稳健，但尚未到“持续高回报护城河”的顶级水平。

**需要注意的是盘口ROE为7.68%，同业表中本公司ROE为7.84%，与2025年报ROE 14.86%口径不同。** 前者更接近最新报告期累计或未年化口径，本文趋势判断以年报序列为准。

结论：**盈利能力有改善，ROE 14.86%、毛利率58.01%、ROIC 12.86%说明公司仍能赚钱，但收入端停滞使高回报的可持续性存在疑问。**

### 解读：利润大体能变成现金，但2025年现金含量下降，资本开支偏中性

**2025年经营现金流仍为正，但利润现金含量下降。** 2025年报经营现金流 **14.90亿**，归母净利润 **16.47亿**，表内经营现金流/净利润为 **88.49%**。该指标分母为含少数股东的净利润口径，但结论不变：2025年每一元利润对应约 **0.88元** 经营现金流，低于2024年 **110.56%** 和2023年 **111.72%**。2025年销售商品收现 **97.86亿**，占营业总收入 **110.01亿** 约 **88.95%**，说明收入中有大约 **11%** 并未在当期全部转化为现金流入。

**自由现金流仍为正，但口径需要说明。** 2025年报自由现金流为 **11.98亿**。需要注意，2024年报自由现金流 **28.78亿** 明显高于经营现金流 **18.25亿** 减去资本开支 **6.37亿** 的简单计算结果，这是因为东财FCFF_BACK口径包含其他调整项，不能直接等同“经营现金流 − 购建固定资产”。因此，跨年度自由现金流比较时要谨慎。

**资本开支稳定，公司并非扩张期。** 2021—2025年资本开支分别为 **4.92亿、5.27亿、6.14亿、6.37亿、6.20亿**，维持在5—6亿左右。收入下滑，资本开支没有明显增加，说明公司没有激进扩产。2026中报购建固定资产 **2.47亿**，节奏与往年接近。公司更像是在维持现有经营规模，而不是进行大规模再投资。

**2026上半年现金净增加额转正。** 2025年报现金净增加 **-9.30亿**，2026中报现金净增加 **8.62亿**。主要变化来自投资现金流由2025中报 **-5.97亿** 转为2026中报 **+4.46亿**，同时筹资现金流净流出由 **-9.08亿** 收窄至 **-1.99亿**。但2026中报经营现金流 **6.21亿** 仍低于2025中报 **6.77亿**，说明日常经营带来的现金流入没有改善。

结论：**利润仍然能转化为现金，自由现金流为正，资本开支中性；但2025年现金含量下降，2026上半年经营现金流继续走弱，不能简单认为“现金奶牛”完全健康。**

### 解读：资产负债表整体稳健，但货币资金下降、应收账款逆势上升

**资产负债率低，短期偿债能力强。** 2025年报资产负债率 **26.62%**，比2024年 **33.41%** 下降 **6.79个百分点**；总负债 **46.30亿**，比2024年 **55.74亿** 减少 **9.44亿**。流动比率 **2.32x**、速动比率 **1.81x**，较2024年的 **1.87x**、**1.47x** 明显改善。短期借款仅 **1.06亿**，占总负债比例很低。2025年报财务费用 **1162.26万**，2026中报 **2033.41万**，金额都不大，说明有息负债压力很小。

**货币资金下降需要关注。** 2025年报货币资金 **19.14亿**，较2024年 **28.51亿** 减少 **9.37亿**，较2023年 **34.62亿** 明显下降。这与2025年现金净增加 **-9.30亿** 相互印证。虽然2026中报现金净增加 **8.62亿**，可能回补一部分现金，但单看2025年报，公司账面现金较前两年明显减少。

**应收账款逆势增长是最大瑕疵。** 2025年报应收 **20.33亿**，较2024年 **17.65亿** 增加 **2.68亿**，增幅约 **15.19%**，而同期营业总收入反而下降 **1.88%**。应收增长快于收入增长，说明回款质量有所转弱。存货 **16.13亿**，与2024年 **15.94亿** 基本持平，较2023年 **16.88亿** 有所下降，存货端没有恶化。

结论：**公司负债率低、流动性好，资产负债表没有生存压力；但货币资金减少和应收账款增加，说明营运资金质量在近一年有所下降。**

### 解读：相对自身历史与同业都偏便宜，但便宜有便宜的原因

**当前估值处于历史最低区域。** 当前PE_TTM **10.19**，略高于全样本最低 **9.97**，远低于中位 **14.55**。PB **1.34**，低于中位 **1.81**，接近最低 **1.20**。PS_TTM **1.52**，低于中位 **1.87**，接近最低 **1.32**。从历史分位看，当前估值是五年内最便宜的一档。

**估值中枢逐年下移。** PE_TTM年度中位数从2022年 **20.52**，到2023年 **15.25**，2024年 **15.92**，2025年 **12.58**，2026年 **11.18**。市场给华润双鹤的估值一路下降，说明资金不再按成长股定价，而是逐步按低增长、价值股定价。

**同业对比也明显低估。** 华润双鹤PE **10.19**，低于复星医药 **17.01**、华东医药 **13.31**、恒瑞医药 **36.65**、科伦药业 **34.22**。PB **1.34**，仅高于复星医药 **1.18**，低于华东医药 **1.81**、科伦药业 **2.54**。这与公司收入停滞、创新属性较弱有关，市场不给成长溢价。

**EV粗算为191.57亿。** 口径为：总市值 **164.41亿** + 总负债 **46.30亿** − 货币资金 **19.14亿** = **191.57亿**。该口径使用2025年报资产负债表数据。当前盈利收益率约 **9.81%**，FCF Yield约 **7.29%**，股息率 **3.03%**，处于低估值、高股息区间。

结论：**相对历史和同业，华润双鹤估值便宜；但这种便宜主要来自收入负增长和成长性缺失，是否是安全边际，需要看内在价值。**

## 七、安全边际：内在价值 vs 当前股价

### 原始数据：安全边际预计算

| 估算项 | 数值 | 口径 |
|---|---:|---|
| 当前股价 | 15.83 | 东财盘口 |
| 总市值 | 164.41亿 | 股价×总股本 |
| EV（粗算） | 191.57亿 | 市值+总负债-货币资金 |
| PE_TTM | 10.19 | 盘口 |
| PB | 1.34 | 盘口 |
| PS_TTM | 1.52 | 盘口 |
| 盈利收益率 | 9.81% | 1/PE_TTM |
| FCF Yield | 7.29% | 最近年报FCF/市值 |
| 历史PE中位 | 14.55 | 东财日频估值序列 |
| 内在价值A | 13.26 | EPS×历史PE中位 |
| 安全边际A | -19.41% | (IV-股价)/IV |
| 内在价值B | 11.54 | 每股FCF×10 |
| 内在价值C | 17.30 | 每股FCF×15 |
| 安全边际B | -37.23% | 对应FCF×10 |

〔来源：东方财富盘口 / 估值分析 / 安全边际预制表〕

### 解读：内在价值A有口径问题，FCF口径下当前安全边际不足

**内在价值A=13.26元不可作为主要依据，因为它用的是半年累计EPS。**  
该计算用EPS **0.911** 乘以历史PE中位 **14.55**，得到 **13.26元**。但 **0.911元** 对应的是**2026中报累计每股收益**，并非年化EPS。用半年累计EPS乘以全年PE，会显著低估内在价值。若改用2025年报EPS **1.595** 乘以历史PE中位 **14.55**，则内在价值约为 **23.21元**，当前股价 **15.83元** 约有 **31.7%** 空间。但这个假设依赖于公司能否回到历史估值中枢，而当前收入负增长，市场未必愿意给14.55倍PE。

**内在价值B=11.54元是悲观/保守口径。**  
2025年报自由现金流 **11.98亿**，总股本 **10.39亿股**，对应每股FCF约 **1.153元**。乘以10倍，得到 **11.54元**。当前股价 **15.83元**，安全边际为 **-37.23%**。这意味着，如果只愿意按10倍自由现金流给价，当前价格不仅没有安全边际，反而高估。

**内在价值C=17.30元是中性口径。**  
每股FCF约 **1.153元**，乘以15倍，得到 **17.30元**。当前股价 **15.83元**，只有约 **8.5%** 的折让。这个折让幅度远不能构成巴菲特式的安全边际。

**我的判断：更认同FCF×15的中性口径，但当前安全边际不足。**  
华润双鹤虽然自由现金流为正，但2025年经营现金流/净利润只有 **88.49%**，收入连续两年负增长，2026中报收入又下滑 **3.44%**。在这种情况下，我不愿意给它历史PE中位14.55倍的乐观估值。以FCF×15的 **17.30元** 作为中性内在价值更稳妥。

**明确买卖区间：**  
- 中性内在价值：**17.30—19.10元**，其中17.30元为FCF×15，19.10元为2025年报EPS 1.595×12倍。  
- 若要求至少20%安全边际，买点应不高于 **13.84元**；若要求30%，应不高于 **12.11元**。  
- 因此，有安全边际的观察/买入区间为 **12.10—13.80元**。当前股价 **15.83元** 处于中性内在价值附近，但没有显著折让，安全边际不够。

结论：**当前价格不贵，但也不到“便宜得令人流口水”的程度。巴菲特式安全边际尚未出现。**

## 八、巴菲特视角评估（结论）

### 1. 生意可理解性：4 / 5

化学制剂、仿制药、大输液等业务模式相对容易理解。公司收入来自药品销售，利润来自出厂价与成本、销售费用之间的差额。但产品管线的持续竞争力、集采降价影响需要专业跟踪。普通投资者能看懂“靠卖药赚钱”，但未必能精确判断未来哪些品种会被集采或替代。因此给4分，而不是5分。

### 2. 财务质量与护城河证据：3 / 5

积极面：2025年报毛利率 **58.01%**，ROE **14.86%**，ROIC **12.86%**，经营现金流 **14.90亿**，自由现金流 **11.98亿**，说明生意本身仍能产生稳定回报。  
消极面：2025年报经营现金流/净利润下降到 **88.49%**，收入连续两年负增长，2026中报收入增速 **-3.44%**。护城河更多体现为历史规模与渠道，而非强大定价权。ROE 14.86%尚可，但净利率提升有费用压缩因素，收入端没有增长支撑。因此财务质量不错，但护城河宽度只能给中等。

### 3. 资产负债表与“活下去”能力：5 / 5

2025年报资产负债率 **26.62%**，流动比率 **2.32x**，速动比率 **1.81x**，短期借款 **1.06亿**，货币资金 **19.14亿**。财务费用仅 **1162.26万**。即使收入继续小幅下滑，公司也没有明显偿债风险。资产负债表这一项接近无瑕疵。

### 4. 当前价格的安全边际：2 / 5

当前股价 **15.83元**，PE_TTM **10.19**，远低于历史中位 **14.55**。但按自由现金流估值，FCF×10对应 **11.54元**，当前价格高估；FCF×15对应 **17.30元**，当前折让仅约 **8.5%**。这个折让不足以覆盖收入负增长和现金流含金量下降的风险。因此安全边际不足。

### 5. 综合判断：观望

公司财务稳健、估值低、股息率 **3.03%**，属于“可以看懂、不会死掉”的公司。但收入端停滞，利润端缺乏增长驱动，当前价格并没有提供足够的错误容忍空间。若股价回落至 **12—14元** 区间，安全边际会明显改善，届时值得进一步研究。

### 6. 巴菲特式追问

**10年后这笔生意还在吗？**  
大概率还在。化学制剂需求刚性，公司资产负债率低，财务风险小，10年内消失的概率很低。但10年后的利润体量取决于集采与产品结构，存在不确定性。

**若股市关闭五年，愿不愿意以今天的价格持有？**  
以 **15.83元** 持有一家ROE **14.86%**、股息率 **3.03%**、自由现金流为正但收入负增长的公司，五年回报可能平庸。不是陷阱，但也不是会让人兴奋的“五年不用看盘”的持股。我个人更愿意等更低价格。

### 7. 一句话结论

**华润双鹤财务扎实、现金流为正、估值低，但收入停滞、成长性不足，当前15.83元安全边际不够，宜观望，12—14元再重点研究。**
